# 第3章 算法分析方法

### 概率分析

#### 3.1

在 `HireAssistant(n)` 中，假设应聘者以随机的顺序出现，正好雇用一次的概率是多少？正好雇用两次的概率是多少？正好雇用 $n$ 次的概率又是多少？

```python
def HireAssistant(n):
    best = 0 
    # 假设所有候选人的评价均大于0分;
    # 此条件下 1 号候选人必然被雇用;
    for i in range(1, n+1):
        interview(candidates[i])
        if candidates[i] > best:
            hire(candidates[i])
            best = candidates[i]
```

答:

> **1.** 正好雇用一次, 即只有 `1号` 候选人被雇用, 后续所有候选人的得分都低于 `1号`;
>
> - 即最高分候选人排在首位, 概率为 $\frac{1}{n}$ ;
>
> **2.** 正好雇用两次, 即 `1号` 之后存在某位候选人 `i号` 被雇用;
> - 而且满足以下条件:
>   - `i号`的得分高于`1号`;
>   - `1~i号`之间的候选人得分低于`1号`;
>   - `i号`之后的候选人得分须低于`i号`;
> 
> - 等价于以下结论:
>   -  `i号`是所有人中得分最高的候选人;
>   -  `i号`之前的候选人中得分最高的要排在`1号`;
>
> - `i` 的取值范围在 `2 ~ n-1` 之中, 各自的概率为:
>   - 若 i = 2, 其余 n-1 人可自由排列, 概率为 $\frac{(n-1)!}{n!} = \frac{1}{n}$;
>   - 若 i = 3, 其余 n-1 人自由排列的基础上, 1号得分必须高于2号, 概率为 $\frac{1}{n} \cdot \frac{1}{2}$;
>   - 若 i = 4, 其余 n-1 人自由排列的基础上, 1号得分必须高于2号和3号, 概率为 $\frac{1}{n} \cdot \frac{1}{3}$;
>   - ...
>   - 若 i = n-1, 其余 n-1 人自由排列的基础上, 1号得分必须是n-1个人中最高的, 概率为 $\frac{1}{n} \cdot \frac{1}{(n-1)}$;
>
> - 故正好雇用两次的概率为: $\frac{1}{n} \cdot (1 + \frac{1}{2} + ... + \frac{1}{(n-1)})$ = $\frac{H_{n-1}}{n}$;
>
> **3.** 正好雇用 $n$ 次, 即每一个候选人都比前一个候选人更好;
>
> - 即应聘者出现顺序按评分严格递增, 概率为: $\frac{1}{n!}$。

#### 3.2

分析 FindMax(A) 算法的平均时间复杂度。

```python
def FindMax(A):
    max = A[0]                  # O(1)
    for i in range(1, len(A)):  # O(1)*(n-1)
        if A[i] > max:          # O(1)*(n-1)
            max = A[i]          # O(1)*k, 0<=k<n
    return max                  # O(1)
```

答:

> 设单次比较操作耗时 $C_1$, 单次赋值操作耗时 $C_2$, 其他操作共耗时 $C_0$;
>
> 比较操作共发生 $n-1$ 次;
> 
> 赋值操作发生的次数 k 取决于输入数据的排列情况:
> - 最好情况下发生 $1$ 次赋值: max = A[0] , 即最大值排在开头, 概率为 $\frac{1}{n}$;
> - 最坏情况下发生 $n$ 次, 即输入数据按升序排列, 概率为 $\frac{1}{n!}$;
> - 平均情况下赋值次数:
>   - 恰好发生 $i$ 次赋值的情况分析复杂, 概率难以计算;
>   - 可以改变求和方式, 统计各个元素 A[i] 发生赋值的概率;
>     - A[0] 发生赋值的概率为 $1$;
>     - A[1] 发生赋值的概率为 $\frac{1}{2}$, 即 A[1] 的得分高于 A[0];
>     - A[2] 发生赋值的概率为 $\frac{1}{3}$, 即 A[2] 的得分高于 A[0] 和 A[1];
>     - ...
>     - A[n-1] 发生赋值的概率为 $\frac{1}{n}$, 即 A[n-1] 的得分高于 A[0], A[1], ..., A[n-2];
>   - 因此平均情况下赋值次数为: $1 + \frac{1}{2} + \frac{1}{3} + ... + \frac{1}{n} = H_n \approx \ln n$;
> 
> 平均时间复杂度为: $T(n) = C_0 + C_1(n-1) + C_2 \times H_n$;
> 得 T(n) = $O(1)$ + $O(n) + O(\ln n)$ = $O(n)$。

### 合计方法 (aggregate method)

**3.3**

如果一组栈运算中包括了一次 `MultiPush` 运算，它一次把 $k$ 个元素压入栈内，那么栈运算分摊费用的界 $O(1)$ 是否还能保持？

**答:**

> 不能保持.
> - Pop 和 MultiPop 的合计费用的上界是 Push 和 MultiPush 的合计费用;
> - n 个栈运算中, 最多能有 n 个 MultiPush, 每个 MultiPush 最多能压入 k 个元素, 因此合计费用为 $O(kn)$。
> - 分摊费用为 $O(k)$。

**3.4**

对某个数据结构执行一个具有 $n$ 个运算的序列。如果 $i$ 为 $2$ 的整数幂，第 $i$ 个运算的费用为 $i$，否则为 $1$。请利用合计方法确定每次运算的分摊费用。

**答:**

> n 个运算中, 费用为 $i$ 的运算的个数 $\leq \log_2 n$ 个, 费用为 $1$ 的运算的个数 $\leq n$ 个; 分别计算两类运算的合计费用:
> - 费用为 $i$ 的运算的合计费用 $\leq 2 + 4 + 8 + ... + 2^{ \log_2 n} = 2^{ (\log_2 n )+ 1} - 2 = 2n-2$;
> - 费用为 $1$ 的运算的合计费用 $\leq n$;
> - $n$ 个运算的合计费用 $T(n) \leq 3n-2 = O(n)$;
> 
> 故单次运算的分摊费用为 $O(1)$。

### 记账方法 (accounting method)

**3.5**

对一个大小从不超过 $N$ 的栈执行一系列的栈运算。在每 $k$ 个运算后，复制整个栈的内容以留作备份。证明对各种栈运算分配合适的分摊费用后，$n$ 个栈运算（包括复制栈的运算）的费用为 $O(n)$。

**答:**

> 分析:
> - 复制栈的成本上界为 $N$, 分摊给它之前的 $k$ 个普通操作, 每个操作承担 $N/k$;
> 
> 证明:
> - 设普通操作分摊费用为 $1+N/k$, 实际费用为 $1$, 每次操作积累余额 $N/k$;
> - 设复制操作分摊费用为 $0$, 实际费用至多为 $N$, 每次操作至多消耗余额 $N$;
> - 每 $k$ 个运算后, 账户余额至少为 $N$, 足以支付一次栈复制;
> - 故 $n$ 个运算总费用 $T(n) < n(1+N/k) = O(n)$。

**3.6**

利用记账方法分析习题3.4。

**答:**

> 分析:
> - 第 $2^k$ 个运算的费用为 $2^k$, 分摊给它之前的 $2^k - 2^{k-1}$ 个运算, 每个运算承担 $2^k/(2^k - 2^{k-1}) = 2$;
>
> 证明:
> - 设普通操作的分摊费用为 $3$, 实际费用为 $1$, 每次操作积累余额 $2$;
> - 设第 $2^k$ 个运算分摊费用为 $2$, 实际费用为 $2^k$, 每次操作消耗余额 $2^k - 2$;
> - 第 $2^k$ 个运算之前的 $(2^k - 2^{k-1} -1)$ 个普通运算积累的余额为 $2^k-2$;
> - 恰好足以支付第 $2^k$ 个运算的消耗;
>
> 故: $n$ 个运算总费用 $T(n) < 3n = O(n)$;
> 单次运算的分摊费用为 $O(1)$。

### 势能方法 (potential method)

**3.7**

假设存在势函数 $Φ$，使得对所有的 $i$ 都有 $Φ(D_i) \ge Φ(D_0)$，但是 $Φ(D_0) \ne 0$。证明存在一个势函数 $Φ'$ 使得 $Φ'(D_0)=0$，且对所有 $i \ge 1$，$Φ'(D_i) \ge 0$，且用 $Φ'$ 表示的分摊费用与用 $Φ$ 表示的分摊费用相同。

**答:**

> 定义 $Φ'(D_i) = Φ(D_i) - Φ(D_0)$, 则:
> - $Φ'(D_0) = Φ(D_0) - Φ(D_0) = 0$;
> - 对所有 $i \ge 1$, $Φ'(D_i) = Φ(D_i) - Φ(D_0) \ge 0$;
>
> 用 $Φ$ 表示的分摊费用:
> - $\hat{c}_i = c_i + Φ(D_i) - Φ(D_{i-1})$;
> 
> 用 $Φ'$ 表示的分摊费用:
> - $\hat{c}_i' = c_i + Φ'(D_i) - Φ'(D_{i-1})$\
>   = $c_i + (Φ(D_i) - Φ(D_0)) - (Φ(D_{i-1}) - Φ(D_0))$\
>   = $c_i + Φ(D_i) - Φ(D_{i-1})$\
>   = $\hat{c}_i$;

**3.8**

用势能方法分析习题3.4。

**答:**

> 定义势函数 $Φ(D_i)$ = (i 距离上一个 $2^k$ 的距离) × 2, 即:
> - $Φ(D_i) = (i - 2^{\lfloor \log_2 i \rfloor}) \times 2$;
>
> 则有:
> - 当 $i \ne 2^k$ 时, $Φ(D_i) > 0$;
> - 当 $i = 2^k$ 时, $Φ(D_i) = 0$;
> 
> 操作 $i$ 的分摊费用: $\hat{c}_i = c_i + Φ(D_i) - Φ(D_{i-1})$:
> - 当 $i = 2^k$ 时, $\hat{c}_i = 2^k + 0 - (2^k - 1- 2^{k-1}) \times 2 = 2$;
> - 当 $i \ne 2^k$ 时, $\hat{c}_i = 1 + ((i - 2^{\lfloor \log_2 i \rfloor}) - ((i-1) - 2^{\lfloor \log_2 (i-1) \rfloor})) \times 2 = 3$:
>
> $n$ 个运算的总费用:
> - $T(n) \leq 3n = O(n)$;
> - 单次运算的分摊费用为 $O(1)$。


**3.9**

假设某个栈在执行 $n$ 个栈运算 `Push`、`Pop` 和 `MultiPop` 之前包含 $S_0$ 个对象，结束后包含 $S_n$ 个对象，试求 $n$ 个栈运算的总费用。

**答:**

> 把 `Push` 记为 `push(1)`; `Pop` 和 `MultiPop` 统一记为 `pop(k)`;
> 
> 设势能函数 $Φ(D_i) = S_i$ ;
> - `push(1)` 的分摊费用 $\hat{c}_i = c_i + S_i - S_{i-1} = 1+1 = 2$;
> - `pop(k)` 的分摊费用 $\hat{c}_j = c_j + S_j - S_{j-1} = c_j + (-c_j) = 0$;
>
> 设 `push(1)` 操作共发生 $m$ 次, $m \leq n$:
> -  $\sum_{i=1}^n \hat{c}_i = \sum_{i=1}^n c_i + Φ(D_n) - Φ(D_0) = \sum_{i=1}^n c_i + S_n - S_0 = 2m$ ;
> 
> $n$ 个栈运算的总费用:
> - $T(n) = \sum_{i=1}^n c_i = 2m + S_0 - S_n$。

**3.10**

对于一个计数器加运算序列，如果计数器不从 $0$ 开始，用势能方法分析该序列的时间复杂度。

**答:**

> 设势能函数 $Φ(D_i)$ = 计数器中 `1` 的位数;
> 
> `计数器+1` 操作的分摊费用: $\hat{c}_i = c_i + Φ(D_i) - Φ(D_{i-1})$:
> - 设 $D_i$ 操作前计数器从最低位起连续 $k$ 位为 1;
> - 则 $D_i$ 操作后这 $k$ 位变为 0, 第 $k+1$ 位由 0 变为 1;
> - $c_i = k+1$;
> - $Φ(D_i) - Φ(D_{i-1}) = (1-k)$;
> - 因此 $\hat{c}_i = (k+1) + (1-k) = 2$;
>
> 分摊费用求和:
> - $\sum_{i=1}^n \hat{c}_i = \sum_{i=1}^n c_i + Φ(D_n) - Φ(D_0) = 2n$;
>
> 实际费用求和:
> - $T(n) = \sum_{i=1}^n c_i = 2n + Φ(D_0) - Φ(D_n) \leq 2n + Φ(D_0)$。
> 
> $Φ(D_0)$ 不会超过计数器的位数, 故:
> - $T(n) = O(n)$。
