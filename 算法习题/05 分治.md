- [x] **5.1**

将合并排序算法改写成迭代算法（非递归算法），并尽可能使算法更有效。

**答:**

> 思路: 把递归过程自底向上迭代实现; 使用两层循环, 外层对应递归树的层数, 内层横向处理单层的所有节点.

```python
# 归并函数
def merge(A, i, l, r):
    # 把待合并的片段复制到两个临时数组中
    L = A[i:i+l]
    R = A[i+l:i+l+r]
    for k in range(i, i+l+r):
        # 从左边取元素的条件: 要么右边元素已取完, 要么两边都还有元素且左边元素较小;
        if not R or (L and L[0] <= R[0]):
            A[k] = L.pop(0)
        # 反之从右边取元素;
        else:
            A[k] = R.pop(0)

# 迭代版归并排序
def merge_sort_iter(A, n):
    # 数组长度小于等于 1, 直接返回
    if n <= 1: return A
    # 以步长 w 对数组进行分段, 初始步长 1, 每轮翻倍;
    w = 1
    # 不变量: 以步长 w 分段得到的每段都是有序的; 末段的长度 0 < length <= w;
    # 循环结束时 w >= n, 整个数组有序;
    while w < n:
        for i in range(0, n, w*2):  # 以步长 w*2 遍历数组, 每次合并两段;
            l = min(w, n - i)       # 左段长度
            r = min(w, n - i - l)   # 右段长度
            if r > 0:               # 右段不为空才需要合并
                merge(A, i, l, r)   # 合并 A[i, i+l) 和 A[i+l, i+l+r)
        print(f"w={w}, A={A}")
        w *= 2
        # 完成一轮合并后宽度翻倍, 直到宽度超过数组长度;
    return A
```


- [x] **LeetCode 35. 搜索插入位置**
  
给定一个严格升序数组和一个目标值，在数组中找到目标值，并返回其索引。

如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

**答:**
```python
# 定义"目标位置"为:目标值存在于数组中的位置或按顺序应插入的位置;
def searchInsert(A, target):
    # 首尾定位指针
    left, right = 0, len(A)
    # 不变量: 目标位置在 [left, right] 范围内;
    # 循环结束时 left == right = 目标位置;
    while left < right:
        # 计算中点位置, 结果只会在 [left, right-1] 范围内;
        mid = (left + right) // 2
        # 目标值 == 中点元素, 目标位置 = mid;
        if target == A[mid]:
            return mid
        # 目标值 > 中点元素, 目标位置在 [mid+1, right];
        elif target > A[mid]:
            left = mid + 1
        # 目标值 < 中点元素, 目标位置在 [left, mid];
        else:
            right = mid
    return left
```


- [x] **LeetCode 50. Pow(x, n)**

实现 $pow(x, n)$, 即 $x^n$, 其中 $n$ 是一个整数 (可以是负数)。

**答:**
```python
def Pow(x, n):
    # 先统一计算正指数的幂, 最后再根据指数符号决定是否取倒数;
    is_negative = (n < 0)
    n = abs(n)
    product = 1

    # 把 n 分解为2的幂次方的和
    # 如 n = 13 = 8 + 4 + 1, 
    # 则 x^n = x^1 * x^4 * x^8;
    # 如此一来, 计算高次幂时可以复用低次幂的计算结果;
    while n > 0:
        # 如果 n 的二进制最低位是 1, 则乘上当前的 x;
        if n % 2 == 1:
            product *= x
        # x 幂次翻倍, n 右移一位;
        x = x * x
        n = n // 2
    # 根据指数符号决定是否取倒数;
    if is_negative:
        product = 1 / product
    return product
```


- [x] **LeetCode 53. 最大子数组和**

给定一个整数数组 `nums`，找到一个具有最大和的子数组 (子数组是数组中的一个连续部分, 且最少包含一个元素) ，返回其最大和。 用分治方法，时间复杂度O(nlgn);

示例：

输入：nums = [-2,1,-3,4,-1,2,1,-5,4]

连续子数组 [4,-1,2,1] 的和最大，

输出: 6

**答:**

```python
def maxSubArray(nums, l, r):
    # 终止条件: 只有一个元素时, 最大子数组和就是该元素本身;
    if l == r:
        return nums[l]
    
    # 将数组划分为两半, 分别寻找左右两半的最大子数组和;
    mid = (l + r) // 2
    left_max = maxSubArray(nums, l, mid)
    right_max = maxSubArray(nums, mid + 1, r)

    # 寻找跨越中点的最大子数组和
    # 从中点向左扫描求最大和
    cross_left_max = float('-inf')
    sum_left = 0
    for i in range(mid, l - 1, -1):
        sum_left += nums[i]
        cross_left_max = max(cross_left_max, sum_left)
    # 从中点向右扫描求最大和
    cross_right_max = float('-inf')
    sum_right = 0
    for i in range(mid + 1, r + 1):
        sum_right += nums[i]
        cross_right_max = max(cross_right_max, sum_right)
    # 跨越中点的最大子数组和
    cross_max = cross_left_max + cross_right_max

    # 返回三者中的最大值;
    return max(left_max, right_max, cross_max)
```


- [x] **LeetCode 69. 平方根**

计算非负整数 x 算术平方根的整数部分;

输入：x = 8, 输出：2

输入：x = 9, 输出：3

**答:**

```python
# 目标: 寻找整数 n 满足 n^2 <= x < (n+1)^2;
# 显然 n 在 [0, x] 之间
# 使用二分法查找
def mySqrt(x):
    left, right = 0, x
    # 不变量: 目标 n 在 [left, right] 范围内;
    # 循环结束时目标 left = right = n;
    while left < right:
        mid = (left + right) // 2
        # 如果 mid^2 恰好等于 x, 直接返回 mid;
        if mid * mid == x:
            return mid
        # 如果 mid^2 < x, 目标 n 在 [mid, right];
        elif mid * mid < x:
            left = mid
        # 如果 x < mid^2, 目标 n 在 [left, mid);
        else:
            right = mid-1
    return left
```

- [x] **LeetCode 215. 数组中的第K个最大元素**


给定整数数组 nums 和整数 k，返回数组中第 k 大的元素。


输入: [3,2,1,5,6,4], k = 2 ,输出: 5



输入: [3,2,3,1,2,4,5,5,6], k = 4, 输出: 4

**答:**

```python
# 划分函数: 以 pivot 为基准把数组划分为左右两部分, 返回 pivot 的最终位置;
def partition(nums, left, right):
    # 选取最右元素作为比较基准
    pivot = nums[right]

    i = left
    # 不变量: [left, i-1] < pivot <= [i, j-1] < pivot <= [j, right-1] <= pivot;
    for j in range(left, right):
        # 从左到右寻找小于 pivot 的元素, 并从左到右填充, 被填充的位置元素与找到的元素交换位置;
        if nums[j] < pivot:
            nums[i], nums[j] = nums[j], nums[i]  # 把小于 pivot 的元素交换到前面
            i += 1
    nums[i], nums[right] = nums[right], nums[i]  # 把 pivot 放到正确的位置
    return i

# 快速选择算法
def quickSelect(nums, left, right, k):
    if left == right: 
        return nums[left]
    
    # 获取切分后的基准点索引
    pivot_index = partition(nums, left, right)
    # 不变量: [left, pivot_index-1] < nums[pivot_index] <= [pivot_index+1, right];
    if k == pivot_index:
        return nums[k]
    elif k < pivot_index:
        # 递归左半部分
        return quickSelect(nums, left, pivot_index - 1, k)
    else:
        # 递归右半部分
        return quickSelect(nums, pivot_index + 1, right, k)
```
