#### 8.2

重写 DFS 算法，用栈结构替代递归。

答:

> 思路: 用栈管理待处理任务:
> - 节点入栈表示加入待访问列表;
> - 节点出栈表示完成访问; 
> - 节点出栈时将其所有邻节点入栈。

```python
def graph_traverse(graph):
    # graph: 用邻接表储存的图

    result = []         # 遍历结果
    visited = set()     # 储存节点访问状态

    # 深度优先遍历 (栈实现)
    def DFS_stack(start):
        # 起始节点入栈
        stack = [start]     # 入栈表示加入待访问列表
        visited.add(start)  # 标记起始节点已入栈
        while stack:
            # 访问栈顶节点
            u = stack.pop()
            result.append(u)
            # 邻居节点入栈
            for v in reversed(graph[u]):     # 逆序入栈, 出栈时顺序才会与递归版一致
                if v not in visited:
                    stack.append(v)
                    visited.add(v)

    # 以每个顶点作为起点进行遍历
    for vertex in graph:
        if vertex not in visited:
            DFS_stack(vertex)
    
    # 输出遍历结果
    print(result)

# 测试
G = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}
graph_traverse(G)
# 输出: ['A', 'B', 'D', 'E', 'F', 'C']
```

#### 8.5

给出一个算法来确定一给定无向图 $G=(V,E)$ 中是否包含环，要求时间复杂度为 O(V)，与 E 无关。

答:

> 使用带父节点信息的 DFS 遍历可以检测环, 时间复杂度是 $O(V+E)$。
>
> 可以在遍历之前检查边和节点数关系, 若 $E \geq V$，则必定存在环。
>
> 排除了 $E \geq V$ 的情况后, 遍历的时间复杂度至多为 $O(2V)$ = $O(V)$。
>
> 环检测思路:
> - 无环的无向图相当于树, 遍历时任意节点只会被访问一次;
> - 有环图遍历时一定会有节点被多次访问, 故只要检测到有节点被二次访问就有环;
> - 由于无向图的边是双向的, 故任意两个邻节点都会被检查为一个环, 故检查二次访问时需要排除相邻节点的二次访问, 使用 src 参数实现;

```python

def has_cycle(graph):
    # graph: 邻接表

    # 计算节点数 O(1)
    V = len(graph)
    # 计算边数 O(V)
    # 无向图每条边被计数两次, 所以除以 2
    E = sum(len(graph[u]) for u in graph) // 2

    print(f"节点数: {V}, 边数: {E}")

    # 边数大于等于节点数，必有环
    if E >= V: return True

    # 边数小于节点数，使用 DFS 检测环
    visited = set()
    def dfs(u, src):
        visited.add(u)
        for v in graph[u]:
            if v == src: continue         # 排除来源节点
            if v in visited: return True  # 发现访问过的节点, 返回 True
            if dfs(v,u):                  # 以 v 为起点继续深搜
                return True               # 深搜返回 True 时返回 True
                                          # 深搜返回 False 时需要继续循环
        return False                      # 搜索完成, 说明无环

    # 以每个节点作为起点进行一次 DFS
    for vertex in graph:
        if vertex not in visited:
            if dfs(vertex, None):
                return True

    # 遍历完毕, 没有发现环
    return False


# 测试

# 有环图
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C']
}
print(has_cycle(graph))  # 输出: True

# 无环图
graph = {
    'A': ['B', 'C'],
    'B': ['A'],
    'C': ['A']
}
print(has_cycle(graph))  # 输出: False
```

#### 8.6

设计一个时间复杂度为 $O(V+E)$ 的算法来计算有向图 $G=(V,E)$ 的连通分支，并且保证所给出算法计算出的连通分支中的每两个顶点间至多只存在一条边。


答：

> 看不太懂题目。是要把含有双向边的分支直接排除掉吗? 
>
> 按此理解的话, 只要在寻找连通分支前, 先将图中的所有双向边删掉, 然后在剩余的图中寻找连通分支即可。
>
> 使用 Kosaraju 算法 $O(V+E)$，在构建反向图时可以顺便排除双向边;
>
> 判断双向边的额外时间复杂度为 $O(E)$，总时间复杂度仍为 $O(V+E)$。


```python
# Kosaraju 算法

def kosaraju(graph):
    # graph: 图用邻接表储存

    # 构建转置图
    graph_T = {u: [] for u in graph}
    for u in graph:
        for v in graph[u]:
            # 双向边的查询可通过建立边哈希表优化为 O(1)
            # 但是为了代码简洁, 这里用内置的 in 操作
            # 时间复杂度为 len(graph[v]) = O(V)
            if u not in graph[v]:   # 排除双向边
                graph_T[v].append(u)

    print('graph_T:', graph_T)

    visited = set()
    topology_stack = []

    # DFS1, 用于生成伪拓扑序列
    def dfs1(u):
        visited.add(u)
        for v in graph[u]:
            if v not in visited:
                dfs1(v)
        topology_stack.append(u)  # 节点完成时入栈

    # DFS2, 在转置图上寻找强连通分量
    def dfs2(u, component):
        visited.add(u)
        component.append(u)
        for v in graph_T.get(u, []):
            if v not in visited:
                dfs2(v, component)

    # 第一次 DFS
    for u in graph:
        if u not in visited:
            dfs1(u)
    
    print('Finish Stack:', topology_stack)

    # 重置访问标记
    visited.clear()

    # 第二次 DFS
    components = []
    for u in reversed(topology_stack):
        if u not in visited:
            component = []
            dfs2(u, component)
            components.append(component)
    
    return components

graph = {
    'A': ['B', 'C'],
    'B': ['A', 'C'],
    'C': ['A', 'D'],
    'D': ['B']
}

print("单边强连通分量:", kosaraju(graph))
# 输出: [['A'], ['B', 'D', 'C']]
```

#### 8.7

给定一个无向图 $G=(V,E)$，它的传递闭包是一个 $0/1$ 数组 $T$，当且仅当 $G$ 中存在一条边数大于 1 的从 $i$ 到 $j$ 的路径时，$T[i,j]=1$。试设计一个计算 $G$ 的传递闭包矩阵的算法，且使其时间复杂度为 $O(V^2)$。

答:

> 无向图的一个连通分支中任意两点之间都存在路径, 只要不是相邻顶点路径就大于1。而相邻顶点之间如果处于一个环中, 也存在大于1的路径。节点自身到自身算相邻节点。
>
> 只需检查两个顶点是否连通, 是否相邻, 以及是否在同一个环中:
>  - 相邻性: 构建邻接矩阵, 一次DFS可实现, 时间复杂度为 O(V+E), 任意两点相邻性检查复杂度为 O(1);
>  - 连通性: 构建连通分支并查表, 一次DFS可实现, 时间复杂度 O(V+E), 任意两点连通性检查复杂度为 O(1);
>  - 同环性: 把无向图的边按遍历顺序改为单向边, 再求此有向图的强连通分量, 此时只有成环的顶点才形成强连通分量。
>     - 用 Hopcroft 算法, 在构建反向图时任何双向边只保留一条边即可;
>  - 构建闭包矩阵, 时间复杂度 $O(V^2)$;
> 
> 简单无向图满足 E < V^2, 故 O(V+E) = O(V^2), 总时间复杂度为 $O(V^2)$;


```python
def Closure(G,N):
    # G: 图用邻接表储存
    # 顶点 id 是从 0 到 N 的整数

    # 邻接矩阵
    adjacent = [[0 for _ in range(N+1)] for _ in range(N+1)]
    # 连通分量
    component = [i for i in range(N+1)]
    # 同环分量
    circle = [i for i in range(N+1)]
    # 传递闭包矩阵
    T = [[0 for _ in range(N+1)] for _ in range(N+1)]

    # 单边反向图
    G_T = {i: [] for i in range(N+1)}
    # 边集
    edges = set()

    # 遍历顺序表
    DFS_result = []

    # DFS 遍历
    visited = set()  # 访问记录表
    def dfs(u):
        visited.add(u)
        DFS_result.append(u)
        adjacent[u][u] = 1      # 邻接矩阵中对角线填 1
        for v in G[u]:
            adjacent[u][v] = 1          # 填写邻接矩阵
            component[v] = component[u] # 合并连通分量
            if (u,v) not in edges:
                G_T[v].append(u)        # 构建单边反向图
                edges.add((u,v))
                edges.add((v,u))
            if v not in visited:
                dfs(v)
    
    # 一次遍历, 获得邻接矩阵,连通分量,遍历顺序表
    for u in G:
        if u not in visited:
            component[u] = u    # 以出发点 id 作为连通分量代表
            dfs(u)
    
    # 二次遍历, 使用单边反向图顺序遍历, 获得环分量
    visited.clear() # 清空访问记录
    
    # 定义遍历函数
    def dfs2(u):
        visited.add(u)
        for v in G_T[u]:
            if v not in visited:
                circle[v] = circle[u]
                dfs2(v)
    
    for u in DFS_result:
        if u not in visited:
            circle[u] = u
            dfs2(u)
        
    # 填写传递闭包矩阵
    for u in range(N+1):
        for v in range(u+1, N+1):
            # 连通且不相邻则填1
            if component[u] == component[v] and adjacent[u][v] == 0:
                T[u][v] = T[v][u] = 1
            # 共环则填1
            if circle[u] == circle[v]:
                T[u][v] = T[v][u] = 1
                T[u][u] = T[v][v] = 1   # 在环中的节点到自身也有大于2的路径 

    # 打印
    print("邻接矩阵:")
    for row in adjacent: print(row)
    print("连通分量:")
    print(component)
    print("同环分量:")
    print(circle)
    print("传递闭包矩阵:")
    for row in T: print(row)


# 测试
G = {
    0: [1, 2],
    1: [0, 2],
    2: [0, 1, 3],
    3: [2],
    4: [5],
    5: [4, 6],
    6: [5],
}
Closure(G,6)

```

#### 8.8

假定图 $G=(V,E)$ 用邻接矩阵表示，试设计一个运行时间为 $O(V^2)$ 的 Prim 算法。

答：

> 用数组 `key[v]` 记录顶点 $v$ 到当前生成树的最小连接代价，`parent[v]` 记录对应父顶点，`inMST[v]` 记录是否已加入树。每轮用线性扫描找出未加入树且 `key` 最小的顶点，再扫描该顶点所在的整行邻接矩阵更新其他顶点的 `key`。

```python
def prim_matrix(weight, root):
    # weight[u][v] 表示边 (u, v) 的权值；不存在边时记为 float('inf')
    n = len(weight)
    key = [float('inf')] * n
    parent = [None] * n
    in_mst = [False] * n

    key[root] = 0

    for _ in range(n):
        # 线性扫描找到当前 key 最小的未加入顶点
        u = -1
        best = float('inf')
        for v in range(n):
            if not in_mst[v] and key[v] < best:
                best = key[v]
                u = v

        in_mst[u] = True

        # 用 u 更新其余顶点的 key 值
        for v in range(n):
            if not in_mst[v] and weight[u][v] != float('inf') and weight[u][v] < key[v]:
                key[v] = weight[u][v]
                parent[v] = u

    return parent, key
```

选取最小 `key` 需要 $O(|V|)$，更新一行邻接矩阵也需要 $O(|V|)$，重复 $|V|$ 次，因此总时间复杂度为 $O(|V|^2)$。

#### 8.9

给定一张图 $G=(V,E)$ 及其一棵最小生成树，假定我们减少图中不属于最小生成树的一条边的权值，试设计一个算法，找出修改边后新图的一棵最小生成树。

答：

设被降低权值的非树边为 $e=(u,v)$，新权值为 $w'(e)$，原最小生成树为 $T$。把 $e$ 加入 $T$ 后，会形成一条唯一回路 $C$。设 $C$ 上权值最大的边为 $f$。

- 若 $w'(e) \ge w(f)$，则原树 $T$ 仍然是新图的一棵最小生成树；
- 若 $w'(e) < w(f)$，则用 $e$ 替换掉 $f$，得到 $T' = T - f + e$，它就是新图的一棵最小生成树。

算法：在树 $T$ 中找到 $u$ 到 $v$ 的唯一路径，扫描该路径上的边找出最大权边 $f$，然后按上面的规则决定是否替换。

正确性来自环性质：在任一回路中，权值最大的边不属于最小生成树；若新边比回路中的最大边更轻，则应当用它替换该边。时间复杂度为在树上找路径的 $O(|V|)$。

#### 8.10

证明 PrimMST 算法的正确性。

答：

证明采用“安全边”与归纳法。

设当前已经选入生成树的边集合为 $A$。Prim 算法在每一步都取连接集合 $S$（已加入树的顶点集）与 $V-S$ 的最小权边 $e$。

由割性质可知：对于任意割 $(S, V-S)$，跨越该割的最轻边是安全边，即存在一棵最小生成树包含 $A \cup \{e\}$。因此如果某一步前 $A$ 可扩展为一棵 MST，那么加入这条最轻跨割边后，新的集合仍可扩展为一棵 MST。

初始时 $A=\varnothing$，显然成立。每次选择都是安全边，所以该性质通过数学归纳法一直保持。算法结束时，$A$ 包含 $|V|-1$ 条边并连通，因此 $A$ 本身就是一棵生成树；又因为它可被某棵 MST 包含，而两者边数相同，只能是最小生成树。

故 PrimMST 算法正确。

#### 8.19

利用合计方法分析 Dijkstra 算法的时间复杂度。

答：

若用优先队列实现 Dijkstra，并按常见的 Fibonacci 堆分析，则：

- 初始化和插入所有顶点：$O(|V|)$；
- 每个顶点最多执行一次 `extract-min`，共 $|V|$ 次，每次均摊代价 $O(log(|V|))$；
- 每条边最多触发一次松弛检查，若发生改进则执行一次 `decrease-key`，共至多 $|E|$ 次，而其均摊代价为 $O(1)$。

因此合计时间为

$$
O(|V| log(|V|) + |E|)
$$

若使用二叉堆，则 `decrease-key` 为 $O(log(|V|))$，总时间变为 $O((|V|+|E|) log(|V|))$；若使用邻接矩阵配合线性扫描，则为 $O(|V|^2)$。

#### 8.22

设 $G=(V,E)$ 为一带权有向图，其权函数 $w:E\to\{0,1,\ldots,W\}$。其中 $W$ 为某非负整数。修改 Dijkstra 算法，使其能够在 $O(W|V|+|E|)$ 时间内计算出给定源点 $s$ 的最短路径。

答：

由于边权是非负整数且上界为 $W$，可使用桶（bucket）实现优先队列，这就是 Dial 算法的思想。

设当前已知的最短距离上界不会超过 $W(|V|-1)$，建立编号为 $0,1,\ldots, W(|V|-1)$ 的桶数组 `B[d]`，每个桶存放当前距离恰好为 $d$ 的顶点。维护一个指针 `cur` 表示当前最小的非空桶。

```python
def bucket_dijkstra(graph, weight, source, max_w):
    # graph[u] 存放 u 的出边终点；weight[(u, v)] 存放边权
    n = len(graph)
    inf = float('inf')
    dist = [inf] * n
    dist[source] = 0

    # 桶的编号对应当前最短距离
    buckets = [[] for _ in range(max_w * n + 1)]
    buckets[0].append(source)
    in_bucket = [False] * n
    in_bucket[source] = True

    cur = 0
    while cur < len(buckets):
        # 跳过空桶，找到当前最小的非空桶
        while cur < len(buckets) and not buckets[cur]:
            cur += 1
        if cur == len(buckets):
            break

        u = buckets[cur].pop()
        in_bucket[u] = False

        for v in graph[u]:
            nd = dist[u] + weight[(u, v)]
            if nd < dist[v]:
                dist[v] = nd
                if in_bucket[v]:
                    # 简化写法：实际实现中可用懒删除或双向链表维护
                    pass
                buckets[nd].append(v)
                in_bucket[v] = True

    return dist
```

每条边只会被扫描一次，因此松弛总代价为 $O(|E|)$；由于最短距离最大不超过 $W(|V|-1)$，`cur` 只会单调前进到该上界，桶扫描总代价为 $O(W|V|)$。故总时间复杂度为 $O(W|V|+|E|)$。

#### 8.27

如何利用 Floyd-Warshall 算法的输出来检测负权回路的存在？

答：

Floyd-Warshall 算法完成后，若存在某个顶点 $i$ 使得 $d[i][i] < 0$，则图中存在负权回路；反之，若图中存在负权回路，则算法结束后必有某个对角元为负。

原因是 $d[i][i]$ 表示从 $i$ 到自身的最短路径长度。如果有负权回路可从 $i$ 到达并回到 $i$，那么沿该回路可得到一条权值为负的闭合路径，从而 $d[i][i] < 0$。因此只需检查结果矩阵的对角线即可：

```python
def has_negative_cycle(dist):
    # dist[i][i] < 0 说明存在从 i 回到 i 的负权回路
    for i in range(len(dist)):
        if dist[i][i] < 0:
            return True
    return False
```
