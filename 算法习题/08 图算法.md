#### 8.2

重写 DFS 算法，用栈结构替代递归。

答：

> 用栈保存待访问节点, 出栈表示已访问; 每出栈一个节点时将其邻节点入栈。为了避免重复访问，用一个 visited 集合标记已经入过栈的节点。对于非连通图，对每个顶点尝试作为起点。

```python
# 用邻接表 graph 储存图
# graph[u] 访问节点 u 的邻居表

def dfs_iterative(graph):
    visited = set()

    # 尝试以每个顶点作为起点, 解决非连通图
    for start in graph:
        if start in visited: continue

        stack = [start]     # 起点入栈
        visited.add(start)  # 标记起点已入栈

        while stack:
            u = stack.pop() # 取出栈顶
            print(u)        # 访问 u
            
            neighbors = graph[u] # 获取 u 的邻居列表
            # 邻节点逆序入栈
            for v in reversed(neighbors):
                if v not in visited:
                    stack.append(v)
                    visited.add(v)

graph = {
    0: [1, 2],
    1: [3],
    2: [3],
    3: []
}

dfs_iterative(graph)
# 预期输出: 0 1 3 2
```


#### 8.5

给出一个算法来确定一给定无向图 $G=(V,E)$ 中是否包含环，要求时间复杂度为 $O(|V|)$，与 $|E|$ 无关。

答:

> 使用遍历法检测环的时间复杂度是 $O(|V|+|E|)$。可以在遍历之前检查边和节点数关系。若 $|E| \geq |V|$，则必定存在环；当 $|E| < |V|$ 时, 遍历的时间复杂度变为 $O(2|V|)$ = $O(|V|)$。

```python
def has_cycle(graph):
    # graph: 邻接表
    V = len(graph)
    E = sum(len(neighbors) for neighbors in graph.values()) // 2  # 无向图每条边被计数两次

    if E >= V:
        return True  # 边数大于等于节点数，必有环
    else:
        # 边数小于节点数，可能无环，需进一步检查
        visited = set()
        def dfs(u, parent):
            visited.add(u)
            for v in graph[u]:
                if v not in visited:
                    if dfs(v, u):
                        return True
                elif v != parent:
                    return True
            return False

        # 对每个顶点尝试作为起点, 进行 DFS 检测环
        for vertex in graph:
            if vertex not in visited:
                if dfs(vertex, None):
                    return True

        return False
```

#### 8.6

设计一个时间复杂度为 $O(|V|+|E|)$ 的算法来计算有向图 $G=(V,E)$ 的连通分支，并且保证所给出算法计算出的连通分支中的每两个顶点间至多只存在一条边。

答：

这里按有向图的强连通分量来理解。先用 Kosaraju 或 Tarjan 算法在 $O(|V|+|E|)$ 时间内求出每个顶点所属的强连通分量编号 `comp[u]`。

然后构造缩点图（condensation graph）：

- 对每条原图边 $(u,v)$，若 `comp[u] != comp[v]`，则在分量 `comp[u]` 到分量 `comp[v]` 之间加边；
- 为了保证任意两点间至多只有一条边，用“按出发分量标记目的分量”的方法去重：对每个分量维护一个临时标记数组 seen，扫描其所有出边时，若目标分量尚未出现过，则加入并标记。

```python
def build_condensation(graph, comp):
    # graph: 邻接表；comp[u]: 顶点 u 所属的强连通分量编号
    condensation = {}

    for u in graph:
        cu = comp[u]
        if cu not in condensation:
            condensation[cu] = []

    for u in graph:
        cu = comp[u]
        seen = set()  # 去掉同一对分量之间的重复边
        for v in graph[u]:
            cv = comp[v]
            if cu != cv and cv not in seen:
                condensation[cu].append(cv)
                seen.add(cv)

    return condensation
```

每条原图边只被扫描常数次，故总时间仍为 $O(|V|+|E|)$；而去重后得到的缩点图中，同一对分量之间最多只有一条边。

#### 8.7

给定一个无向图 $G=(V,E)$，它的传递闭包是一个 $0/1$ 数组 $T$，当且仅当 $G$ 中存在一条边数大于 1 的从 $i$ 到 $j$ 的路径时，$T[i,j]=1$。试设计一个计算 $G$ 的传递闭包矩阵的算法，且使其时间复杂度为 $O(|V|^2)$。

答：

因为是无向图，任意 $i \ne j$ 满足 $T[i,j]=1$ 的充要条件是：$i$ 和 $j$ 在同一连通分量中，且要么它们不直接相邻，要么边 $(i,j)$ 位于某个回路上（即存在另一条 $i$ 到 $j$ 的路径）。

可用一次 DFS 在 $O(|V|^2)$ 时间内求出每条边是否为桥，并得到连通分量编号。若图用邻接矩阵表示，DFS 扫描邻接点本身就是 $O(|V|^2)$。

于是有：

- 若 `comp[i] != comp[j]`，则 $T[i,j]=0$；
- 若 $i=j$，则 $T[i,i]=0$；
- 若 $(i,j)$ 不是 $E$ 中的边，且 `comp[i] = comp[j]`，则任意 $i\to j$ 的简单路径长度至少为 $2$，故 $T[i,j]=1$；
- 若 $(i,j) \in E$，则只有当该边不是桥时，才存在一条长度大于 $1$ 的替代路径，故此时 $T[i,j]=1$；若该边是桥，则 $T[i,j]=0$。

因而算法为：先求连通分量与桥，再按上述规则填表。整个过程时间复杂度为 $O(|V|^2)$。

#### 8.8

假定图 $G=(V,E)$ 用邻接矩阵表示，试设计一个运行时间为 $O(|V|^2)$ 的 Prim 算法。

答：

用数组 `key[v]` 记录顶点 $v$ 到当前生成树的最小连接代价，`parent[v]` 记录对应父顶点，`inMST[v]` 记录是否已加入树。每轮用线性扫描找出未加入树且 `key` 最小的顶点，再扫描该顶点所在的整行邻接矩阵更新其他顶点的 `key`。

```python
def prim_matrix(weight, root):
    # weight[u][v] 表示边 (u, v) 的权值；不存在边时记为 float('inf')
    n = len(weight)
    key = [float('inf')] * n
    parent = [None] * n
    in_mst = [False] * n

    key[root] = 0

    for _ in range(n):
        # 线性扫描找到当前 key 最小的未加入顶点
        u = -1
        best = float('inf')
        for v in range(n):
            if not in_mst[v] and key[v] < best:
                best = key[v]
                u = v

        in_mst[u] = True

        # 用 u 更新其余顶点的 key 值
        for v in range(n):
            if not in_mst[v] and weight[u][v] != float('inf') and weight[u][v] < key[v]:
                key[v] = weight[u][v]
                parent[v] = u

    return parent, key
```

选取最小 `key` 需要 $O(|V|)$，更新一行邻接矩阵也需要 $O(|V|)$，重复 $|V|$ 次，因此总时间复杂度为 $O(|V|^2)$。

#### 8.9

给定一张图 $G=(V,E)$ 及其一棵最小生成树，假定我们减少图中不属于最小生成树的一条边的权值，试设计一个算法，找出修改边后新图的一棵最小生成树。

答：

设被降低权值的非树边为 $e=(u,v)$，新权值为 $w'(e)$，原最小生成树为 $T$。把 $e$ 加入 $T$ 后，会形成一条唯一回路 $C$。设 $C$ 上权值最大的边为 $f$。

- 若 $w'(e) \ge w(f)$，则原树 $T$ 仍然是新图的一棵最小生成树；
- 若 $w'(e) < w(f)$，则用 $e$ 替换掉 $f$，得到 $T' = T - f + e$，它就是新图的一棵最小生成树。

算法：在树 $T$ 中找到 $u$ 到 $v$ 的唯一路径，扫描该路径上的边找出最大权边 $f$，然后按上面的规则决定是否替换。

正确性来自环性质：在任一回路中，权值最大的边不属于最小生成树；若新边比回路中的最大边更轻，则应当用它替换该边。时间复杂度为在树上找路径的 $O(|V|)$。

#### 8.10

证明 PrimMST 算法的正确性。

答：

证明采用“安全边”与归纳法。

设当前已经选入生成树的边集合为 $A$。Prim 算法在每一步都取连接集合 $S$（已加入树的顶点集）与 $V-S$ 的最小权边 $e$。

由割性质可知：对于任意割 $(S, V-S)$，跨越该割的最轻边是安全边，即存在一棵最小生成树包含 $A \cup \{e\}$。因此如果某一步前 $A$ 可扩展为一棵 MST，那么加入这条最轻跨割边后，新的集合仍可扩展为一棵 MST。

初始时 $A=\varnothing$，显然成立。每次选择都是安全边，所以该性质通过数学归纳法一直保持。算法结束时，$A$ 包含 $|V|-1$ 条边并连通，因此 $A$ 本身就是一棵生成树；又因为它可被某棵 MST 包含，而两者边数相同，只能是最小生成树。

故 PrimMST 算法正确。

#### 8.19

利用合计方法分析 Dijkstra 算法的时间复杂度。

答：

若用优先队列实现 Dijkstra，并按常见的 Fibonacci 堆分析，则：

- 初始化和插入所有顶点：$O(|V|)$；
- 每个顶点最多执行一次 `extract-min`，共 $|V|$ 次，每次均摊代价 $O(log(|V|))$；
- 每条边最多触发一次松弛检查，若发生改进则执行一次 `decrease-key`，共至多 $|E|$ 次，而其均摊代价为 $O(1)$。

因此合计时间为

$$
O(|V| log(|V|) + |E|)
$$

若使用二叉堆，则 `decrease-key` 为 $O(log(|V|))$，总时间变为 $O((|V|+|E|) log(|V|))$；若使用邻接矩阵配合线性扫描，则为 $O(|V|^2)$。

#### 8.22

设 $G=(V,E)$ 为一带权有向图，其权函数 $w:E\to\{0,1,\ldots,W\}$。其中 $W$ 为某非负整数。修改 Dijkstra 算法，使其能够在 $O(W|V|+|E|)$ 时间内计算出给定源点 $s$ 的最短路径。

答：

由于边权是非负整数且上界为 $W$，可使用桶（bucket）实现优先队列，这就是 Dial 算法的思想。

设当前已知的最短距离上界不会超过 $W(|V|-1)$，建立编号为 $0,1,\ldots, W(|V|-1)$ 的桶数组 `B[d]`，每个桶存放当前距离恰好为 $d$ 的顶点。维护一个指针 `cur` 表示当前最小的非空桶。

```python
def bucket_dijkstra(graph, weight, source, max_w):
    # graph[u] 存放 u 的出边终点；weight[(u, v)] 存放边权
    n = len(graph)
    inf = float('inf')
    dist = [inf] * n
    dist[source] = 0

    # 桶的编号对应当前最短距离
    buckets = [[] for _ in range(max_w * n + 1)]
    buckets[0].append(source)
    in_bucket = [False] * n
    in_bucket[source] = True

    cur = 0
    while cur < len(buckets):
        # 跳过空桶，找到当前最小的非空桶
        while cur < len(buckets) and not buckets[cur]:
            cur += 1
        if cur == len(buckets):
            break

        u = buckets[cur].pop()
        in_bucket[u] = False

        for v in graph[u]:
            nd = dist[u] + weight[(u, v)]
            if nd < dist[v]:
                dist[v] = nd
                if in_bucket[v]:
                    # 简化写法：实际实现中可用懒删除或双向链表维护
                    pass
                buckets[nd].append(v)
                in_bucket[v] = True

    return dist
```

每条边只会被扫描一次，因此松弛总代价为 $O(|E|)$；由于最短距离最大不超过 $W(|V|-1)$，`cur` 只会单调前进到该上界，桶扫描总代价为 $O(W|V|)$。故总时间复杂度为 $O(W|V|+|E|)$。

#### 8.27

如何利用 Floyd-Warshall 算法的输出来检测负权回路的存在？

答：

Floyd-Warshall 算法完成后，若存在某个顶点 $i$ 使得 $d[i][i] < 0$，则图中存在负权回路；反之，若图中存在负权回路，则算法结束后必有某个对角元为负。

原因是 $d[i][i]$ 表示从 $i$ 到自身的最短路径长度。如果有负权回路可从 $i$ 到达并回到 $i$，那么沿该回路可得到一条权值为负的闭合路径，从而 $d[i][i] < 0$。因此只需检查结果矩阵的对角线即可：

```python
def has_negative_cycle(dist):
    # dist[i][i] < 0 说明存在从 i 回到 i 的负权回路
    for i in range(len(dist)):
        if dist[i][i] < 0:
            return True
    return False
```
