#### 1.8 算法的正确性

证明下列计算 $a^n$ 的迭代算法的正确性:

```python
def Exp(a, n):
    pow = 1
    i = 0
    while i < n:
        pow = pow * a
        i = i + 1
    return pow
```

答:

> 迭代不变量为 $P_i: pow = a^{i}$;
> 
> - 迭代开始前: $i = 0, pow = 1 = a^0$, $P_0$ 成立;
> - 若第 i 次迭代前 $P_i$ 成立, 即 pow = $a^{i}$, 则第 i 次迭代后 $pow = a^{i} * a = a^{i+1}$, 故 $P_{i+1}$ 成立;
> - 迭代结束时: $i = n$, $P_n$ 成立, 即 $pow = a^n$;
>
> 故算法正确.



#### 1.5 时间复杂度

> 分析找 n 个数中最大值的算法 FindMax(A) 的时间复杂度。

答:

```python
def FindMax(A):
    m = A[0]                    # O(1)
    for i in range(1, len(A)):  # O(1)*(n-1)
        if A[i] > m:            # O(1)*(n-1)
            m = A[i]            # O(1)*k, 0<=k<n
    return m                    # O(1)
```

> 逐行分析得:
> T(n) = O(1) * (1 + (n-1) + (n-1) + k + 1)\
> = O(1) * (2n - 1 + k)\
> < O(1) * 3n
> = O(n)



#### 1.9 问题的下界

给定 n 个数，请设计一个找指定数 x 的算法并证明算法的正确性，分析其时间复杂度, 讨论该算法是不是最有效算法。

**答:**

```python
# 假设 x 在 A 中最早出现的位置为 p, 0<=p<=n
# 以 p = n 代表 x 不在 A 中的情况
# 算法如下:
def Find(A, x):
    n = len(A)
    for i in range(0, n):   # O(1)*(p+1)
        if A[i] == x:       # O(1)*(p+1)
            return i        # O(1)
    return n                # O(1)
```

正确性证明:

> 迭代不变量 $P_i$: x 不在 $A[0...i-1]$ 中;
> 
> - 迭代开始前: $i = 0, A[0...-1]$ 是空集, $x$ 不在其, 故 $P_0$ 成立。
> - 若第 $i$ 次迭代前 $P_i$ 成立, 则第 $i$ 次迭代后:
>   - 若 $A[i] == x$, 循环结束, 返回 $i$, 算法正确;
>   - 若 $A[i] != x$, 则 $x$ 不在 $A[0...i]$ 中, 故 $P_{i+1}$ 成立。
> - 循环结束时: 要么已经找到 $x$, 要么 $i = n$, $P_n$ 成立, $x$ 不在 $A[0...n-1]$ 中; 总之算法正确。
>

时间复杂度:

> $T(n) = O(1) * (p+1 + p+1 + 1) = O(p+1)$
> - 最好情况: $p = 0, T(n) = O(1)$
> - 最坏情况: $p = n, T(n) = O(n)$
> - 平均情况: 不知道 $p$ 的概率分布, 无法分析。


问题的下界:

> 在无序数组中寻找 x, 每次检查最多只能排除一个元素, 最坏情况下必须检查每个元素, 因此下界为 $\Omega(n)$。该算法已经是最有效算法。
