#### 2 

定义最优化问题: `LongestPathLength：给定一个无向图以及两个顶点，求这两个顶点间的最长简单路径的长度（所包含的边数）`。

再定义判定问题: `LongestPath = { <G, u, v, k> : G = (V, E) 是一个无向图，u, v ∈ V，k ≥ 0 是一个整数，且 G 中从 u 到 v 存在一条长度至少为 k 的简单路径 }`
 
证明最优化问题 `LongestPathLength` 可以在多项式时间内解决，当且仅当 `LongestPath` 能够在多项式时间内解决。

##### 答:

1.必要性: ($\text{LongestPathLength}  =>\text{LongestPath}$)
>
> 假设 LongestPathLength 可以在多项式时间内解决。 则对于任意输入 <G, u, v, k>, 可以调用 LongestPathLength(<G, u, v>) 来求出从 u 到 v 的最长简单路径长度 l. 如果 l >= k 则返回 True; 否则返回 False. 因此 LongestPath 也可以在多项式时间内解决.
```python
def LongestPath(G, u, v, k):
    l = LongestPathLength(G, u, v)
    return l >= k
```

2.充分性: ($\text{LongestPath} =>\text{LongestPathLength}$)
>
> 假设 LongestPath 可以在多项式时间内解决, 则对于任意输入 <G, u, v>, 假设图 G 中的顶点数为 n, 则可以通过二分法来求出从 u 到 v 的最长简单路径长度 l. 具体方法是:
> - 初始化 low = 0, high = n-1;
> - 当 low <= high 时, 计算 mid = (low + high) // 2;
> - 调用 LongestPath(<G, u, v, mid>) 来判断是否存在长度至少为 mid 的简单路径;
> - 如果存在, 则更新 low = mid + 1; 否则更新 high = mid - 1;
> - 最终 low 的值即为从 u 到 v 的最长简单路径长度 l.
> 
> 最多 O(log n) 次调用 LongestPath, 故可以在多项式时间内解决.

```python
def LongestPathLength(G, u, v):
    low = 0
    high = len(G.nodes) - 1
    while low <= high:
        mid = (low + high) // 2
        if LongestPath(G, u, v, mid):
            low = mid + 1
        else:
            high = mid - 1
    return low
```

假设 TSP 判定问题的求解算法是多项式时间算法，试设计一个算法，求出旅行商问题最短回路的权值。

##### 答: 

TSP_Decision(G, k) 能判断图 G 中是否存在一个回路，其权值不超过 k。可以通过二分法来求出最短回路的权值：

```python
def TSP_Optimization(G):
    # 计算图 G 中所有边的权值范围
    min_weight = min(weight for u in G for v, weight in G[u])
    max_weight = sum(weight for u in G for v, weight in G[u])
    
    low = min_weight
    high = max_weight
    
    while low < high:
        mid = (low + high) // 2
        if TSP_Decision(G, mid):
            high = mid  # 存在回路，尝试更小的权值
        else:
            low = mid + 1  # 不存在回路，尝试更大的权值
            
    return low  # 最短回路的权值
```

##### 答:

>假设存在一个多项式时间算法 HamCycle(G) 来判断一个图 G 是否存在汉密尔顿回路。可以使用删边法获得一个汉密尔顿回路图：

```python
def find_hamiltonian_cycle(G):
    if not HamCycle(G):
        return None  # 没有汉密尔顿回路
    
    cycle = []
    edges = list(G.edges())
    
    for u, v in edges:
        G.remove_edge(u, v)  # 尝试删除边
        if not HamCycle(G):  # 判断删除后是否仍有回路 
        #O(n^p) * E < O(n^p) * n^2 = O(n^(p+2))
            cycle.append((u, v)) # 该边是回路的一部分
            G.add_edge(u, v)     # 恢复边
    
    return cycle  # 返回回路边列表
```

#### 16

已知一个 m×n 整数矩阵 A 和一个 m 维整数向量 b，0/1 整数规划问题是：是否存在其元素属于集合 {0,1} 的 n 维整数向量 x，使得 Ax ≤ b。证明 0/1 整数规划问题是 NP 完全的。（提示：约简到 3-CNF-SAT。）

##### 答:

1. 证明 0/1 整数规划问题属于 NP

>候选解（Certificate）：一个 $n$ 维的整数向量 $x = (x_1, x_2, \dots, x_n)^T$。

>验证算法（Verification Algorithm）：

检查 $x$ 中的每个元素 $x_i$ 是否都在 $\{0, 1\}$ 集合中。需要检查 $n$ 次。

计算矩阵与向量的乘积 $A \cdot x$，并验证是否满足每一行 $i$ 都有 $(Ax)_i \le b_i$。

复杂度分析：矩阵乘法 $A_{m \times n} \times x_{n \times 1}$ 的计算需要进行 $m \times n$ 次乘法和加法。验证所有的不等式需要 $m$ 次比较。这些操作的总时间复杂度为 $O(m \cdot n)$，显然在输入规模的多项式时间内。因此，0/1 整数规划问题属于 NP。
