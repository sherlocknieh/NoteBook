#### 1.2

> 给定一个算法，其输入是一个整数集 S 和一个整数 m, 输出是和为 m 的所有 S
> 的子集，算法的具体步骤如下：
>
> 1. 列出S的全部子集，并求它们的和。
> 2. 逐个查看步骤 1 列出的子集，把每个和等于 m 的子集输出。
>
> 上述流程是否满足算法的特点？请说明理由。

- [x] 答:

  该流程满足算法的特点;

  1. `输入输出明确`: 输入是一个整数集 $S$ 和一个整数 $m$，输出是和为 $m$ 的所有
     $S$ 的子集。
  2. `有穷性`: 由于子集数量为 $2^n$，算法必将停止。
  3. `确定性`: 对于相同的输入，算法的每一步骤都有明确的结果。
  4. `可行性`: 每一步骤都可以在有限时间内完成。

#### 1.5

> 参考插入排序算法运行时间的分析，分析找 n 个数中最大值的算法 FindMax(A)
> 的时间复杂度。

```python
def FindMax(A):
    max = A[0]
    for i in range(1, len(A)):
        if A[i] > max:
            max = A[i]
    return max
```

- [ ] 答:

  算法 FindMax(A) 的时间复杂度为 O(n)，其中 n 是数组 A
  的长度。因为算法需要遍历数组中的每个元素一次，以比较并找到最大值，所以其运行时间与数组的大小成线性关系。

#### 1.8

> 利用循环不变量证明下列计算 $a^n$ 算法的正确性:

```python
def Exp(a, n):
    i = 1
    pow = 1
    while i <= n:
        pow = pow * a
        i = i + 1
    return pow
```

- [ ] 答:

定义循环不变量为 $P$：在每次循环迭代开始前，变量 pow 的值满足：pow = $a^{i-1}$.

- 开始时: i = 1 时, pow = 1 = $a^0$, 循环不变量成立。
- 第 i 次迭代: 假设 i = k 时, 循环不变量成立, 即 pow = $a^{k-1}$。
- 则 i = k+1 时, pow = $a^{k-1} \times a = a^k$，循环不变量仍然成立。
- 循环结束时: i = n + 1, pow = $a^n$，算法正确。
