# 第2章 渐进复杂度分析

**2.1**
设 $f(n)=3n^2 +2n - 3$, $g(n)=5n^2-n +2$, 证明 $f(n)=\Theta(g(n))$。

- 证:

> $\lim_{n\to\infty}\frac{f(n)}{g(n)}$
>
> = $\lim_{n\to\infty}\frac{3n^2 +2n - 3}{5n^2-n +2}$
>
> = $\lim_{n\to\infty}\frac{3 + \frac{2}{n} - \frac{3}{n^2}}{5 - \frac{1}{n} + \frac{2}{n^2}}$
>
> = $\frac{3}{5}$;
>
> 故 $f(n)=\Theta(g(n))$。


**2.2**
设 $f(n)$ 和 $g(n)$ 都是渐近非负函数。利用符号 $\Theta$ 的基本定义来证明 $\max(f(n), g(n)) = \Theta(f(n) + g(n))$。

- 证:

>  $f(n)$ 和 $g(n)$ 都是渐近非负函数, 即存在常数 $n_0$, 当 $n>n_0$ 时, $f(n) \geq 0$ 且 $g(n) \geq 0$。
>
> 故 $n>n_0$ 时, $\frac{1}{2}(f(n) + g(n)) \leq \max(f(n), g(n)) \leq f(n) + g(n)$ 显然成立。
> 
> 即 $\max(f(n), g(n)) = \Theta(f(n) + g(n))$。

**2.3**
证明对于任意给定的实常数 $a$ 和 $b$，其中 $b>0$，有 $(n + a)^b = \Theta(n^b)$。

- 证:

> $\lim_{n\to\infty}\frac{(n + a)^b}{n^b}$
>
> = $\lim_{n\to\infty}\left(\frac{n + a}{n}\right)^b$
>
> = $\lim_{n\to\infty}\left(1 + \frac{a}{n}\right)^b$
>
> = $1^b = 1$;
>
> 故 $(n + a)^b = \Theta(n^b)$。


**2.9**
证明定理2.1。

- 证:

> 必要性:
> - $f(n) = \Theta(g(n))$ $\iff$ 存在常数 $c_1$, $c_2$, $n_0$ 使得对于所有 $n \geq n_0$, $c_2 g(n) \leq f(n) \leq c_1 g(n)$。
> - 显然 $f(n) = O(g(n))$ 且 $f(n) = \Omega(g(n))$。
>
> 充分性:
> 1. $f(n) = O(g(n))$ $\iff$ 存在常数 $c_1$ 和 $n_1$ 使得对于所有 $n \geq n_1$, $f(n) \leq c_1 (n)$。
> 2. $f(n) = \Omega(g(n))$ $\iff$ 存在常数 $c_2$ 和 $n_2$ 使得对于所有 $n \geq n_2$, $f(n) \geq c_2 g(n)$。
> - 由 1. 和 2. $\implies$ 存在常数 $c_1$, $c_2$, $n_0= \max(n_1, n_2)$ 使得对于所有 $n \geq n_0$, $c_2 g(n) \leq f(n) \leq c_1 g(n)$, 即 $f(n) = \Theta(g(n))$。
