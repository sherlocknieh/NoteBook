### 3.1 雇用助手问题 (概率分析)

在 `HireAssistant(n)` 中，假设应聘者以随机的顺序出现，正好雇用一次的概率是多少？正好雇用两次的概率是多少？正好雇用 $n$ 次的概率又是多少？

```python
def HireAssistant(n):
    best = 0 
    # 假设后续雇用的候选人的打分均 > 0
    for i in range(1, n+1):
        interview(candidate[i])
        if candidate[i] > best:
            best = candidate[i]
            hire(candidate[best])
```

- [ ] 答:

> - 正好雇用一次:
>   - 即第 1 个候选人被雇用, 后续的候选人都不好于第 1 个候选人;
>   - 概率为: $\frac{1}{n}$ ;
> - 正好雇用两次:
>   - 即第 1 个和第 i 个候选人被雇用, i > 1 ; (1,i) 之间的候选人都不好于第 1 个候选人, 后续的候选人都不好于第 i 个候选人;

> - 正好雇用 n 次:
>   - 每一个候选人都比前一个候选人更好
>   - 概率为: $\frac{1}{n!}$。
