### 概率分析

**3.1**
在 `HireAssistant(n)` 中，假设应聘者以随机的顺序出现，正好雇用一次的概率是多少？正好雇用两次的概率是多少？正好雇用 $n$ 次的概率又是多少？

```python
def HireAssistant(n):
    best = 0 
    # 假设候选人的得分均 > 0, 且每个候选人的得分互不相同
    for i in range(0, n):
        面试(候选人[i])
        if 候选人[i] > best:
            雇佣(候选人[i])
            best = 候选人[i]
```

答:

> `正好雇用一次`, 即 `候选人[0]` 被雇用, 且后续的候选人都不好于 `候选人[0]`;
> - 即最高分候选人排在首位, 概率为: $\frac{1}{n}$ ;
>
> 正好雇用两次, 即 候选人[0] 和 候选人[i] 被雇用, (i > 0); 且 (1,i) 之间的候选人都不好于 候选人[0], i 之后后续的候选人都不好于 候选人[i];
> - 概率为: $\frac{1}{n(n-1)}$ ;
>
> 正好雇用 $n$ 次, 即每一个候选人都比前一个候选人更好;
> - 概率为: $\frac{1}{n!}$。
