### 概率分析

**3.1** #DOING

在 `HireAssistant(n)` 中，假设应聘者以随机的顺序出现，正好雇用一次的概率是多少？正好雇用两次的概率是多少？正好雇用 $n$ 次的概率又是多少？

```python
def HireAssistant(n):
    best = 0 
    # 假设候选人的得分均 > 0, 且每个候选人的得分互不相同
    for i in range(1, n+1):
        面试(候选人[i])
        if 候选人[i] > best:
            雇佣(候选人[i])
            best = 候选人[i]
```

**答:**

> (1) 正好雇用一次, 即只有 `1号` 候选人被雇用, 后续所有候选人的得分都低于 `1号`;
>
> - 即最高分候选人排在首位, 概率为 $\frac{1}{n}$ ;
>
> (2) 正好雇用两次, 即 `1号` 之后存在某位候选人 `i号` 被雇用, 并且 `1~i号` 之间的候选人得分都低于 `1号`, 且 `i号` 的得分高于 `1号`, 且 `i号` 之后的候选人得分都低于 `i号`;
>
> - `i` 是 `2~n-1` 中的一个数;
>   - i = 2 的情况, 没有别的约束, 概率为 $\frac{1}{n}$;
>   - i = 3 的情况, 2号得分须低于1号, 概率为 $\frac{1}{n-1}$;
>   - ...
>   - i = n-1 的情况, 概率为 $\frac{1}{n}$;
>
> (3) 正好雇用 $n$ 次, 即每一个候选人都比前一个候选人更好;
>
> - 即应聘者是按评分严格递增, 概率为: $\frac{1}{n!}$。
