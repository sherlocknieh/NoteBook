### 概率分析

**3.1**

在 `HireAssistant(n)` 中，假设应聘者以随机的顺序出现，正好雇用一次的概率是多少？正好雇用两次的概率是多少？正好雇用 $n$ 次的概率又是多少？

```python
def HireAssistant(n):
    best = 0 
    # 假设候选人的得分均 > 0, 且每个候选人的得分互不相同;
    # 此条件下显然 1 号候选人必然被雇用;
    for i in range(1, n+1):
        面试(候选人[i])
        if 候选人[i] > best:
            雇佣(候选人[i])
            best = 候选人[i]
```

**答:**

> **(1)** 正好雇用一次, 即只有 `1号` 候选人被雇用, 后续所有候选人的得分都低于 `1号`;
>
> - 即最高分候选人排在首位, 概率为 $\frac{1}{n}$ ;
>
> **(2)** 正好雇用两次, 即 `1号` 之后存在某位候选人 `i号` 被雇用;
> - 需满足以下条件:
>   - `i号` 的得分必然高于 `1号`;
>   - `1号` 之后, `i号` 之前的候选人得分必然低于 `1号`;
>   - `i号` 之后的候选人得分必然低于 `i号`;
> 
> - 等价于以下结论:
>   -  `i号` 必然是所有人中得分最高的候选人;
>   -  `i号` 之前出现的候选人中得分最高的一个必须排在 `1号`;
>
> - i 只能在 2 ~ n-1 中选择:
>   - 若 i = 2, 其余 n-1 人可自由排列, 概率为 $\frac{(n-1)!}{n!} = \frac{1}{n}$;
>   - 若 i = 3, 其余 n-1 人自由排列的基础上, 1号得分必须高于2号, 概率为 $\frac{1}{n} \cdot \frac{1}{2}$;
>   - 若 i = 4, 其余 n-1 人自由排列的基础上, 1号得分必须高于2号和3号, 概率为 $\frac{1}{n} \cdot \frac{1}{3}$;
>   - ...
>   - 若 i = n-1, 其余 n-1 人自由排列的基础上, 1号得分必须是n-1个人中最高的, 概率为 $\frac{1}{n} \cdot \frac{1}{(n-1)}$;
>
> - 正好雇用两次的概率为: $\frac{1}{n} \cdot (1 + \frac{1}{2} + ... + \frac{1}{(n-1)})$ = $\frac{H_{n-1}}{n}$;
>
> **(3)** 正好雇用 $n$ 次, 即每一个候选人都比前一个候选人更好;
>
> - 即应聘者出现顺序按评分严格递增, 概率为: $\frac{1}{n!}$。

请分析习题1.5，找 $n$ 个数中最大值算法 FindMax(A) 的平均时间复杂度。

```python
def FindMax(A):
    max = A[0]
    for i in range(1, len(A)):
        if A[i] > max:
            max = A[i]
    return max
```

**答:**

> 算法主要包含比较操作和赋值操作;
> 
> 设单次比较操作耗时 $C_1$, 单次赋值操作耗时 $C_2$, 其他操作共耗时 $C_0$;
>
> 比较操作共发生 $n-1$ 次;
> 
> 赋值操作发生的次数取决于输入数据的排列情况:
> - 最好情况下发生 $1$ 次, 即 A[0] 为最大值, 概率为 $\frac{1}{n}$;
> - 最坏情况下发生 $n$ 次, 即输入数据按升序排列, 概率为 $\frac{1}{n!}$;
> - 平均情况下发生的赋值次数为: $\frac{1}{n} \cdot 1 + \frac{1}{n!} \cdot n + ...$ = $\frac{H_n}{n}$;
> 
> 总时间复杂度为: $T(n) = C_0 + C_1(n-1) + C_2 \times (赋值次数)$;
