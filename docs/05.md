将合并排序算法改写成迭代算法（非递归算法），并尽可能使算法更有效。

> 思路: 把递归过程自底向上迭代实现; 使用两层循环, 外层对应递归树的层数, 内层处理单层的所有横向节点.

```python
def merge(A, i, j, k):
    # 合并 A[i, j) 和 A[j, k) 两个有序子数组
    pass

def merge_sort_iter(A, n):
    # 初始宽度为 2, 即每两个元素合并成一个有序数组;
    width = 2
    # 完成一轮合并后宽度翻倍, 每四个元素合并一次;
    while width <= n:
        for i in range(0, n, width):
            merge(A, i, width)
        width *= 2
    return A
```
