### 递归算法设计

**4.1**

设计一个递归算法，在有 $n$ 个元素的序列 $A[1..n]$ 中搜索元素 $x$。

**答:**

> ```python
> def Search(x, A, low, high):
>     # 若区间长度已为0, 直接返回
>     if low == high: return
>     # 若区间长度不为0, 到中间位置找
>     mid = (low + high) // 2
>     # 如果找到, 输出位置
>     if A[mid] == x:
>         print(mid)
>     # 如果没找到, 继续在左右两边找
>     else:
>         Search(x, A, low, mid)
>         Search(x, A, mid + 1, high)
> ```


**4.2**

给定含有 $n$ 个元素的数组 $A$，请设计一个算法找出数组 $A$ 中出现次数最多的元素，并输出该元素出现的次数。

例如：$A = \{1,1,2,2,2,3,5\}$，$A$ 中出现次数最多的元素是 $2$，出现次数为 $3$。

**答:**

> ```python
> def MostElementIn(A):
>     hashTable = {}
>     mostElement = None
>     mostCount = 0
>     for x in A:
>         hashTable[x] = hashTable.get(x, 0) + 1
>         if hashTable[x] > mostCount:
>             mostCount = hashTable[x]
>             mostElement = x
>     print(mostElement, mostCount)
> ```

**4.3**

将第 1 章的插入排序算法改写为递归算法，并分析其时间复杂度。

**答:**

> ```python
> # 递归插入排序:
> def InsertionSort(A, n):
>     # 递归出口: 当 n <= 1 时, 数组已经有序  
>     if n <= 1: return
>     # 先把前 n-1 个元素排序好
>     InsertionSort(A, n - 1)
>     # 再将第 n 个元素插入到前 n-1 个元素中
>     i = n - 1
>     while i > 0 and A[i] < A[i - 1]:
>         A[i], A[i - 1] = A[i - 1], A[i]
>         i -= 1
> ```
> 时间复杂度分析:
> - $T(1) = \Theta(1)$
> - $T(n) = T(n-1) + (n-1), (n > 1)$
>
> 得: $T(n) = O(n^2)$。
