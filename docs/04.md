- [x] **4.1**

设计一个递归算法，在有 $n$ 个元素的序列 $A[1..n]$ 中搜索元素 $x$。

**答:**

```python
def Search(x, A, low, high):
    # 若区间长度已为0, 直接返回
    if low == high: return
    # 若区间长度不为0, 到中间位置找
    mid = (low + high) // 2
    # 如果找到, 输出位置
    if A[mid] == x:
        print(mid)
    # 如果没找到, 继续在左右两边找
    else:
        Search(x, A, low, mid)
        Search(x, A, mid + 1, high)
```


- [x] **4.2**

给定含有 $n$ 个元素的数组 $A$，请设计一个算法找出数组 $A$ 中出现次数最多的元素，并输出该元素出现的次数。

例如：$A = \{1,1,2,2,2,3,5\}$，$A$ 中出现次数最多的元素是 $2$，出现次数为 $3$。

**答:**

```python
def MostElementIn(A):
    hashTable = {}
    mostElement = None
    mostCount = 0
    for x in A:
        hashTable[x] = hashTable.get(x, 0) + 1
        if hashTable[x] > mostCount:
            mostCount = hashTable[x]
            mostElement = x
    print(mostElement, mostCount)
```

- [x] **4.3**

将第 1 章的插入排序算法改写为递归算法，并分析其时间复杂度。

**答:**

```python
# 递归插入排序:
def InsertionSort(A, n):
    # 递归出口: 当 n <= 1 时, 数组已经有序  
    if n <= 1: return
    # 先把前 n-1 个元素排序好
    InsertionSort(A, n - 1)
    # 再将第 n 个元素插入到前 n-1 个元素中
    i = n - 1
    while i > 0 and A[i] < A[i - 1]:
        A[i], A[i - 1] = A[i - 1], A[i]
        i -= 1
```
> 时间复杂度分析:
> - $T(1) = \Theta(1)$
> - $T(n) = T(n-1) + O(n-1), (n > 1)$
>
> $T(n) = \Theta(1)+O(1)+O(2)+...+O(n-1) = O(n^2)$。

- [x] **4.4**

证明算法 `GeneratingPerm1` 的正确性。

```python
# 交换法生成排列
# 数组 P[1..n] 初始时储存了元素 {1,2,..,n} 的一个排列; 
# 不变量: Perm1(m) 生成 P[m,m+1,...,n] 的全排列, 且调用前后数组中元素顺序不变;
def Perm1(m):
    if m == n:
        output(P[1..n])
    else:
        for i in range(m, n + 1):
            P[m], P[i] = P[i], P[m] # 交换 P[i] 与 P[m] 

            Perm1(m + 1)     # 对 P[m+1..n] 进行全排列;
            #且结束后 P[m+1..n] 的元素顺序与调用前一致;

            P[m], P[i] = P[i], P[m] # 交换 P[i] 与 P[m] 

# 生成 {1,2,..,n} 的全排列
def GeneratingPerm1():
    for i in range(1, n + 1):
        P[i] = i
    Perm1(1)
```

**答:**

> 对函数 `Perm1(m)` 定义递归不变量 $I_m$:
> 
> - "`Perm1(m)` 会正确产生 $P[m,m+1,...,n]$ 的全排列, 且调用前后不改变 $P[m,m+1,...,n]$ 中元素顺序";
>
> 证明:
> 
> - 当 $m=n$ 时, `Perm1(m)` 产生 $P[n]$ 的全排列, 显然满足 $I_n$;
> - 假设 $I_{m+1}$ 成立,则 `Perm1(m)` 中:
>   - 第`i`轮循环中:
>     - 先将 $P[i]$ 与 $P[m]$ 交换位置;
>     - 然后正确生成以$P[i]$ 开头的 $P[m+1..n]$ 的全排列, 且调用前后未改变元素顺序;
>     - 最后再把 $P[i]$ 与 $P[m]$ 交换位置;
>     - 故每次循环前后也不改变元素顺序; 
>   - 经 `n+1-m` 次循环后, 将生成以 $P[m,m+1,...,n]$ 中每个元素开头的剩余元素的全排列, 即 $P[m,m+1,...,n]$ 的全排列, 且不改变数组中的原始顺序;
>   - 因此 $I_m$ 成立;
> - 综上, $I_1$ 成立, 即 `GeneratingPerm1()` 会正确产生 $P[1,2,...,n]$ 的全排列。

**4.5**

修改算法 `Perm1`，使其能够按照字典序输出排列.


**答:**

```python
def dictPerm1(m):
    if m == n:
        output(P[1..n])
    else:
        for i in range(m, n + 1):
            for j in range(i, m, -1):
                P[j], P[j - 1] = P[j - 1], P[j]
            dictPerm1(m + 1)
            for j in range(m + 1, i + 1):
                P[j], P[j - 1] = P[j - 1], P[j]
```
> 说明:
> - 在每次递归循环中, 不是直接将 $P[i]$ 与 $P[m]$ 交换位置;
> - 而是把 $P[i]$ 插入到 $P[m]$ 的位置, 原 $P[m]$ 到 $P[i-1]$ 的元素统一后移一位;
> - 这样可使 $P[m+1,..,n]$ 维持升序, 从而保证下一层递归中的循环按升序进行, 最终的输出将按字典序排列;
> 
> 例如: 
> - [1,3,2] 会依次生成 1 开头, 3 开头, 2 开头的排列, 开头就不符合字典序; 
> - 而 [1,2,3] 会依次生成 1 开头, 2 开头, 3 开头的排列, 开头符合字典序。
> - 只要开头符合字典序, 且去掉开头后剩余元素也维持字典序, 则递归输出的排列将符合字典序。

**4.6**

请仔细解释，为什么算法 `GeneratingPerm2` 中，当过程 `Perm2` 以 `Perm2(m), (m > 0)` 形式调用时，数组 $P$ 恰好包含 $m$ 个 $0$，并且 `Perm2(m-1)` 将恰好执行 $m$ 次。
```python
# 放置法生成排列
# 数组 P[1..n] 初始值全为0;
# 不变量: Perm2(m) 生成 {1,2,...,m} 在 P[1..n] 中未被占用 (值为0) 的 m 个位置中的所有排列方式, 调用前后不改变数组状态;
def Perm2(m):
    if m == 0:
        output(P[1..n])
    else:
        for i in range(1, n + 1):
            if P[i] != 0: continue
            P[i] = m
            Perm2(m - 1)
            P[i] = 0

# 生成 P[1..n] 的全排列
def GeneratingPerm2():
    for i in range(1, n + 1):
        P[i] = 0
    Perm2(n)
```


**答:**

> `GeneratingPerm2()` 中, `Perm2` 的初始参数为 $n$;
> 
> 调用 `Perm2(n)` 时, P 中 n 个位置均为 0; 程序会先将 $n$ 放在 P[1], P[2], ..., P[n] 中的一个位置上, 并调用一次 `Perm2(n-1)`, 调用结束后又会将该位置重置为 $0$, 如此循环 $n$ 次;
>
> 故每个 `Perm2(n-1)` 被调用时, 正好被 $n$ 占据了一个位置, 还剩 $n-1$ 个为 $0$ 的位置;
>
> 同理, 当`Perm2(n-2)` 被调用时, $n$ 和 $n-1$ 已经占据了 $2$ 个位置, 剩余 $n-2$ 个为 $0$ 的位置;
>
> 当 `Perm2(m)` 被调用时, $n, n-1, ..., m+1$ 已经占据了 $n-m$ 个位置, 剩余 $m$ 个为 $0$ 的位置; `Perm2(m-1)` 将被调用 $m$ 次, 每次占据一个位置, 直到 $m-1$ 个位置被占据, 剩余 $0$ 个位置;
