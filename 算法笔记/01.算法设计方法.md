# 第1章 算法的核心概念


#### 1.不变量方法

1. 概念的萌芽：罗伯特·弗洛伊德（Robert Floyd）
1967年，弗洛伊德发表了一篇划时代的论文《分配给程序的意义》（Assigning Meanings to Programs）。当时人们主要用流程图来表达程序，弗洛伊德提出：可以在流程图的各个节点（尤其是循环的入口和出口）标记一些“断言”（Assertions）——即在这一点必须为真的数学逻辑命题。 这其实就是循环不变式的雏形，他用这种方法来证明程序会结束且结果正确。

1969年，快排（Quicksort）的发明者托尼·霍尔发表了《计算机编程的公理基础》（An Axiomatic Basis for Computer Programming），提出了著名的“霍尔三元组”（Hoare Triple），形式为：$$\{P\} \ C \ \{Q\}$$（意思是：如果前置条件 $P$ 成立，执行程序 $C$ 后，后置条件 $Q$ 必然成立。）在这篇论文中，为了处理循环结构（while 循环），霍尔正式引入了循环不变式（Loop Invariant）的概念和推理规则。可以说，是霍尔真正把循环不变式变成了现代软件工程和逻辑学中的标准术语。

弗洛伊德和霍尔的方法是“事后证明”——即程序已经写好了，你拿循环不变式去检查它对不对。


他在1975年提出了最弱前置条件（Weakest Precondition, WP）理论，把霍尔的逻辑颠倒了过来：

“不要先写代码再证明。我们要从‘目标（后置条件）’出发，利用循环不变式作为‘图纸’，逆向推导出代码应该怎么写。”

他把循环不变式从一个“质检工具”变成了一个“研发工具”。这就是前文提到的“标准策略”。大卫·格里斯（David Gries）后来把迪杰斯特拉的这一套方法整理成了名著《编程的科学》（The Science of Programming），使得这种“通过不变式在几分钟内推导出高效算法”的方法学在学术界名声大噪。

迪杰斯特拉的“标准策略”


证明下列计算 $a^n$ 的迭代算法的正确性:

```python
def Exp(a, n):
    pow = 1
    i = 0
    while i < n:
        pow = pow * a
        i = i + 1
    return pow
```

答:

> 迭代不变量为 $P_i: pow = a^{i}$;
> 
> - 迭代开始前: $i = 0, pow = 1 = a^0$, $P_0$ 成立;
> - 若第 i 次迭代前 $P_i$ 成立, 即 pow = $a^{i}$, 则第 i 次迭代后 $pow = a^{i} * a = a^{i+1}$, 故 $P_{i+1}$ 成立;
> - 迭代结束时: $i = n$, $P_n$ 成立, 即 $pow = a^n$;
>
> 故算法正确.



#### 2.时间复杂度

> 分析找 n 个数中最大值的算法 FindMax(A) 的时间复杂度。

答:

```python
def FindMax(A):
    m = A[0]                    # O(1)
    for i in range(1, len(A)):  # O(1)*(n-1)
        if A[i] > m:            # O(1)*(n-1)
            m = A[i]            # O(1)*k, 0<=k<n
    return m                    # O(1)
```

> 逐行分析得:
> T(n) = O(1) * (1 + (n-1) + (n-1) + k + 1)\
> = O(1) * (2n - 1 + k)\
> < O(1) * 3n
> = O(n)


#### 2.1 渐进符号的定义 (极限定义)

设 $f(n)=3n^2 +2n - 3$, $g(n)=5n^2-n +2$,
证明 $f(n)=\Theta(g(n))$;

证:

> $\lim_{n\to\infty}\frac{f(n)}{g(n)}$
>
> = $\lim_{n\to\infty}\frac{3n^2 +2n - 3}{5n^2-n +2}$
>
> = $\lim_{n\to\infty}\frac{3 + \frac{2}{n} - \frac{3}{n^2}}{5 - \frac{1}{n} + \frac{2}{n^2}}$
>
> = $\frac{3}{5}$;
>
> 故 $f(n)=\Theta(g(n))$。

#### 2.2 渐进符号的定义 (不等式定义)

设 $f(n)$ 和 $g(n)$ 都是渐近非负函数。
证明 $\max(f(n), g(n)) = \Theta(f(n) + g(n))$。

证:


> 命题 $\iff$ $\exists c_1, c_2, n_0 > 0$, 当 $n > n_0$ 时, $c_1(f(n) + g(n)) \leq \max(f(n), g(n)) \leq c_2(f(n) + g(n))$;
> 
> 显然有: $\frac{1}{2}(f(n) + g(n)) \leq \max(f(n), g(n)) \leq f(n) + g(n)$;
> 
> 故命题成立。


#### 1.9 问题的下界

给定 n 个数，请设计一个找指定数 x 的算法并证明算法的正确性，分析其时间复杂度, 讨论该算法是不是最有效算法。

**答:**

```python
# 假设 x 在 A 中最早出现的位置为 p, 0<=p<=n
# 以 p = n 代表 x 不在 A 中的情况
# 算法如下:
def Find(A, x):
    n = len(A)
    for i in range(0, n):   # O(1)*(p+1)
        if A[i] == x:       # O(1)*(p+1)
            return i        # O(1)
    return n                # O(1)
```

正确性证明:

> 迭代不变量 $P_i$: x 不在 $A[0...i-1]$ 中;
> 
> - 迭代开始前: $i = 0, A[0...-1]$ 是空集, $x$ 不在其, 故 $P_0$ 成立。
> - 若第 $i$ 次迭代前 $P_i$ 成立, 则第 $i$ 次迭代后:
>   - 若 $A[i] == x$, 循环结束, 返回 $i$, 算法正确;
>   - 若 $A[i] != x$, 则 $x$ 不在 $A[0...i]$ 中, 故 $P_{i+1}$ 成立。
> - 循环结束时: 要么已经找到 $x$, 要么 $i = n$, $P_n$ 成立, $x$ 不在 $A[0...n-1]$ 中; 总之算法正确。
>

时间复杂度:

> $T(n) = O(1) * (p+1 + p+1 + 1) = O(p+1)$
> - 最好情况: $p = 0, T(n) = O(1)$
> - 最坏情况: $p = n, T(n) = O(n)$
> - 平均情况: 不知道 $p$ 的概率分布, 无法分析。


问题的下界:

> 在无序数组中寻找 x, 每次检查最多只能排除一个元素, 最坏情况下必须检查每个元素, 因此下界为 $\Omega(n)$。该算法已经是最有效算法。
