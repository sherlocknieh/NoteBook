## 输入数据二分

- [x] 二分查找
  
给定一个严格升序数组和一个目标值，在数组中找到目标值，并返回其索引。

如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

**答:**
```python
# 定义"目标位置"为:目标值存在于数组中的位置或按顺序应插入的位置;
def searchInsert(A, target):
    # 首尾定位指针
    left, right = 0, len(A)
    # 不变量: 目标位置在 [left, right] 范围内;
    # 循环结束时 left == right = 目标位置;
    while left < right:
        # 计算中点位置, 结果只会在 [left, right-1] 范围内;
        mid = (left + right) // 2
        # 目标值 == 中点元素, 目标位置 = mid;
        if target == A[mid]:
            return mid
        # 目标值 > 中点元素, 目标位置在 [mid+1, right];
        elif target > A[mid]:
            left = mid + 1
        # 目标值 < 中点元素, 目标位置在 [left, mid];
        else:
            right = mid
    return left
```

- [x] Top-k 快速选择算法

给定整数数组 nums 和整数 k，返回数组中第 k 大的元素。

**答:**

```python
# 划分函数: 以 pivot 为基准把数组划分为左右两部分, 返回 pivot 的最终位置;
def partition(nums, left, right):
    # 选取最右元素作为比较基准
    pivot = nums[right]

    i = left
    # 不变量: [left, i-1] < pivot <= [i, j-1] < pivot <= [j, right-1] <= pivot;
    for j in range(left, right):
        # 从左到右寻找小于 pivot 的元素, 并从左到右填充, 被填充的位置元素与找到的元素交换位置;
        if nums[j] < pivot:
            nums[i], nums[j] = nums[j], nums[i]  # 把小于 pivot 的元素交换到前面
            i += 1
    nums[i], nums[right] = nums[right], nums[i]  # 把 pivot 放到正确的位置
    return i

# 快速选择算法
def quick_selection(nums, left, right, k):
    if left == right: 
        return nums[left]
    
    # 获取切分后的基准点索引
    pivot_index = partition(nums, left, right)
    # 不变量: [left, pivot_index-1] < nums[pivot_index] <= [pivot_index+1, right];
    if k == pivot_index:
        return nums[k]
    elif k < pivot_index:
        # 递归左半部分
        return quick_selection(nums, left, pivot_index - 1, k)
    else:
        # 递归右半部分
        return quick_selection(nums, pivot_index + 1, right, k)

# 测试
nums = [3,2,1,5,6,4]
k = 2
print(quick_selection(nums, 0, len(nums) - 1, len(nums) - k))  # 输出: 5
nums = [3,2,3,1,2,4,5,5,6]
k = 4
print(quick_selection(nums, 0, len(nums) - 1, len(nums) - k))  # 输出: 4
```




- [x] 最大和区间

给定一个有正数有负数的数组 `nums`，寻找一个连续子区间使区间求和最大，并输出这个最大和。

target = max(sum(nums[i:j]) for 0 <= i < j <= len(nums))

**答:**

```python
def maxSubArray(nums, l, r):
    # 终止条件: 只有一个元素时, 最大子数组和就是该元素本身;
    if l == r:
        return nums[l]
    
    # 将数组划分为两半, 分别寻找左右两半的最大子数组和;
    mid = (l + r) // 2
    left_max = maxSubArray(nums, l, mid)
    right_max = maxSubArray(nums, mid + 1, r)

    # 寻找跨越中点的最大子数组和
    # 从中点向左扫描求最大和
    cross_left_max = float('-inf')
    sum_left = 0
    for i in range(mid, l - 1, -1):
        sum_left += nums[i]
        cross_left_max = max(cross_left_max, sum_left)
    # 从中点向右扫描求最大和
    cross_right_max = float('-inf')
    sum_right = 0
    for i in range(mid + 1, r + 1):
        sum_right += nums[i]
        cross_right_max = max(cross_right_max, sum_right)
    # 跨越中点的最大子数组和
    cross_max = cross_left_max + cross_right_max

    # 返回三者中的最大值;
    return max(left_max, right_max, cross_max)

# 测试
nums = [-2,1,-3,4,-1,2,1,-5,4]
print(maxSubArray(nums, 0, len(nums) - 1))  # 输出: 6
最终结果: 连续子数组 [4,-1,2,1] 的和最大，输出: 6
```
