# 第1章 算法的核心概念

#### 0.理解算法

算法是解决特定问题的一系列明确指令。

特点:

- 输入: 算法接受零个或多个输入值;
- 输出: 算法至少产生一个输出值;
- 确定性: 算法的每一步都有明确的定义, 不存在歧义;
- 有限性: 算法必须在有限的步骤内完成;
- 可行性: 算法的每一步都必须是可行的, 即在有限时间内可以执行.

理解: 

- 算法只要求执行者具有基础逻辑判断能力, 只需要按照指令执行即可, 不需要用到任何主观智力, 比如创造力, 直觉等; 因此算法通过设计机器来执行, 可以大大提高效率和准确性; 早期的算法执行者是人,叫做"计算员(Computer)"; 现在的算法执行者是计算机, 也叫做 Computer;



#### 1.算法正确性分析

证明下列计算 $a^n$ 的迭代算法的正确性:

```python
def Exp(a, n):
    pow = 1
    i = 0
    while i < n:
        pow = pow * a
        i = i + 1
    return pow
```

答:

> 迭代不变量为 $P_i: pow = a^{i}$;
> 
> - 迭代开始前: $i = 0, pow = 1 = a^0$, $P_0$ 成立;
> - 若第 i 次迭代前 $P_i$ 成立, 即 pow = $a^{i}$, 则第 i 次迭代后 $pow = a^{i} * a = a^{i+1}$, 故 $P_{i+1}$ 成立;
> - 迭代结束时: $i = n$, $P_n$ 成立, 即 $pow = a^n$;
>
> 故算法正确.


证明算法 `GeneratingPerm1` 的正确性。

```python
# 交换法生成排列
# 数组 P[1..n] 初始时储存了元素 {1,2,..,n} 的一个排列; 
# 不变量: Perm1(m) 生成 P[m,m+1,...,n] 的全排列, 且调用前后数组中元素顺序不变;
def Perm1(m):
    if m == n:
        output(P[1..n])
    else:
        for i in range(m, n + 1):
            P[m], P[i] = P[i], P[m] # 交换 P[i] 与 P[m] 

            Perm1(m + 1)     # 对 P[m+1..n] 进行全排列;
            #且结束后 P[m+1..n] 的元素顺序与调用前一致;

            P[m], P[i] = P[i], P[m] # 交换 P[i] 与 P[m] 

# 生成 {1,2,..,n} 的全排列
def GeneratingPerm1():
    for i in range(1, n + 1):
        P[i] = i
    Perm1(1)
```

**答:**

> 对函数 `Perm1(m)` 定义递归不变量 $I_m$:
>
> - "`Perm1(m)` 会正确产生 $P[m,m+1,...,n]$ 的全排列, 且调用前后不改变 $P[m,m+1,...,n]$ 中元素顺序";
>
> 证明:
>
> - 当 $m=n$ 时, `Perm1(m)` 产生 $P[n]$ 的全排列, 显然满足 $I_n$;
> - 假设 $I_{m+1}$ 成立,则 `Perm1(m)` 中:
>   - 第 `i`轮循环中:
>     - 先将 $P[i]$ 与 $P[m]$ 交换位置;
>     - 然后正确生成以$P[i]$ 开头的 $P[m+1..n]$ 的全排列, 且调用前后未改变元素顺序;
>     - 最后再把 $P[i]$ 与 $P[m]$ 交换位置;
>     - 故每次循环前后也不改变元素顺序;
>   - 经 `n+1-m` 次循环后, 将生成以 $P[m,m+1,...,n]$ 中每个元素开头的剩余元素的全排列, 即 $P[m,m+1,...,n]$ 的全排列, 且不改变数组中的原始顺序;
>   - 因此 $I_m$ 成立;
> - 综上, $I_1$ 成立, 即 `GeneratingPerm1()` 会正确产生 $P[1,2,...,n]$ 的全排列。


#### 2.时间复杂度

> 分析找 n 个数中最大值的算法 FindMax(A) 的时间复杂度。

答:

```python
def FindMax(A):
    m = A[0]                    # O(1)
    for i in range(1, len(A)):  # O(1)*(n-1)
        if A[i] > m:            # O(1)*(n-1)
            m = A[i]            # O(1)*k, 0<=k<n
    return m                    # O(1)
```

> 逐行分析得:
> T(n) = O(1) * (1 + (n-1) + (n-1) + k + 1)\
> = O(1) * (2n - 1 + k)\
> < O(1) * 3n
> = O(n)


#### 2.1 渐进符号的定义 (极限定义)

设 $f(n)=3n^2 +2n - 3$, $g(n)=5n^2-n +2$,
证明 $f(n)=\Theta(g(n))$;

证:

> $\lim_{n\to\infty}\frac{f(n)}{g(n)}$
>
> = $\lim_{n\to\infty}\frac{3n^2 +2n - 3}{5n^2-n +2}$
>
> = $\lim_{n\to\infty}\frac{3 + \frac{2}{n} - \frac{3}{n^2}}{5 - \frac{1}{n} + \frac{2}{n^2}}$
>
> = $\frac{3}{5}$;
>
> 故 $f(n)=\Theta(g(n))$。

#### 2.2 渐进符号的定义 (不等式定义)

设 $f(n)$ 和 $g(n)$ 都是渐近非负函数。
证明 $\max(f(n), g(n)) = \Theta(f(n) + g(n))$。

证:


> 命题 $\iff$ $\exists c_1, c_2, n_0 > 0$, 当 $n > n_0$ 时, $c_1(f(n) + g(n)) \leq \max(f(n), g(n)) \leq c_2(f(n) + g(n))$;
> 
> 显然有: $\frac{1}{2}(f(n) + g(n)) \leq \max(f(n), g(n)) \leq f(n) + g(n)$;
> 
> 故命题成立。


#### 1.9 问题的下界

给定 n 个数，请设计一个找指定数 x 的算法并证明算法的正确性，分析其时间复杂度, 讨论该算法是不是最有效算法。

**答:**

```python
# 假设 x 在 A 中最早出现的位置为 p, 0<=p<=n
# 以 p = n 代表 x 不在 A 中的情况
# 算法如下:
def Find(A, x):
    n = len(A)
    for i in range(0, n):   # O(1)*(p+1)
        if A[i] == x:       # O(1)*(p+1)
            return i        # O(1)
    return n                # O(1)
```

正确性证明:

> 迭代不变量 $P_i$: x 不在 $A[0...i-1]$ 中;
> 
> - 迭代开始前: $i = 0, A[0...-1]$ 是空集, $x$ 不在其, 故 $P_0$ 成立。
> - 若第 $i$ 次迭代前 $P_i$ 成立, 则第 $i$ 次迭代后:
>   - 若 $A[i] == x$, 循环结束, 返回 $i$, 算法正确;
>   - 若 $A[i] != x$, 则 $x$ 不在 $A[0...i]$ 中, 故 $P_{i+1}$ 成立。
> - 循环结束时: 要么已经找到 $x$, 要么 $i = n$, $P_n$ 成立, $x$ 不在 $A[0...n-1]$ 中; 总之算法正确。
>

时间复杂度:

> $T(n) = O(1) * (p+1 + p+1 + 1) = O(p+1)$
> - 最好情况: $p = 0, T(n) = O(1)$
> - 最坏情况: $p = n, T(n) = O(n)$
> - 平均情况: 不知道 $p$ 的概率分布, 无法分析。


问题的下界:

> 在无序数组中寻找 x, 每次检查最多只能排除一个元素, 最坏情况下必须检查每个元素, 因此下界为 $\Omega(n)$。该算法已经是最有效算法。
