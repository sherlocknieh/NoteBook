**1.2**

给定一个算法，其输入是一个整数集 S 和一个整数 m, 输出是和为 m 的所有 S 的子集，算法的具体步骤如下：

1. 列出S的全部子集，并求它们的和。
2. 逐个查看步骤 1 列出的子集，把每个和等于 m 的子集输出。

上述流程是否满足算法的特点？请说明理由。

**答:**

> 该流程满足算法的特点;
>
> - `输入输出明确`: 输入是一个整数集 $S$ 和一个整数 $m$，输出是和为 $m$ 的所有 $S$ 的子集。
> - `有穷性`: 由于子集数量 $2^n$ 有限, 算法必将停止。
> - `确定性`: 每一步操作都明确无歧义。
> - `可行性`: 每一步都可以在有限时间内完成。

**1.5** 

参考插入排序算法运行时间的分析，分析找 n 个数中最大值的算法 FindMax(A) 的时间复杂度。

```python
def FindMax(A):
    max = A[0]
    for i in range(1, len(A)):
        if A[i] > max:
            max = A[i]
    return max
```

**答:**

> 算法 FindMax(A) 的时间复杂度为 O(n); 因为无论最大值在哪一位, 都必须遍历完数组，才能确定它是最大值, 而遍历一遍数组必然能找到最大值, 故时间复杂度为 O(n)。

**1.6**

证明算法 FindMax(A) 的正确性。

**答:**

> 设循环不变量 P(i): max 是 A[0], A[1], ..., A[i-1] 中的最大元素。
>
> - 初始时: i = 1, max = A[0], P(1) 成立。
> - 若第 i 次迭代前 P(i) 成立, 则第 i 次迭代后, max 是 A[0], A[1], ..., A[i] 中的最大元素, 即 P(i+1) 成立。
> - 循环结束时: i = n, P(n) 成立, 即 max 是 A[0], A[1], ..., A[n-1] 中的最大元素, 算法正确。

**1.7**

给出一个算法，使之能输出数组 A[1], A[2], ..., A[n] 中最后出现的最大元素的下标。

**答:**

> ```python
> def FindLastMaxIndex(A):
>     index = 0
>     for i in range(1, len(A)):
>         if A[i] >= A[index]:
>             index = i
>     return index
> ```

**1.8**

利用循环不变量证明下列计算 $a^n$ 算法的正确性:

```python
def Exp(a, n):
    i = 1
    pow = 1
    while i <= n:
        pow = pow * a
        i = i + 1
    return pow
```

**答:**

> 设循环不变量 P(i): pow = $a^{i-1}$.
>
> - 开始时: i = 1 时, pow = 1 = $a^0$; P(1) 成立;
> - 假设第 i 次迭代前, P(i)成立, 即 pow = $a^{i-1}$, 则第 i 次迭代后, pow = $a^{i-1} * a = a^i$; 故 P(i+1) 成立。
> - 循环结束时: i = n + 1, P(n) 成立, 即 pow = $a^n$，算法正确。

**1.9**

给定n个数，请设计一个找指定数 x 的算法，分析其时间复杂度并证明算法的正确性。所设计的算法是最有效算法吗？

**答:**

> **(1) 算法设计:**
>
> ```python
> def FindX(A, x):
>     for i in range(0, len(A)):
>         if A[i] == x:
>             return i
>     return -1
> ```
>
> **(2) 正确性证明:**
>
> 设循环不变量 P(i): 数 x 不在 A[0...i-1] 中;
> 
> - 初始时: i = 0, A[0...-1] 是空集, 数 x 不在其, 故 P(0) 成立。
> - 若第 i 次迭代前 P(i) 成立, 则第 i 次迭代后:
>   - 若 A[i] == x, 循环结束, 返回 i;
>   - 若 A[i] != x, 则数 x 不在 A[0...i] 中, 故 P(i+1) 成立。
> - 循环结束时: 要么已经找到x, 要么 i = n, P(n) 成立, 数 x 不在 A[0...n-1] 中; 总之算法正确。
>
> **(3) 时间复杂度:**
>
> - 最好情况: 数 x 恰好在 A[0], 则只需一次比较, 时间复杂度为 O(1);
> - 最坏情况: 数 x 不在 A[0...n-1] 中, 则需 n 次比较, 时间复杂度为 O(n);
> - 平均情况: 数 x 随机出现或不在 A[0...n-1] 中, 平均比较次数为 $\frac{n}{2}$, 时间复杂度为 O(n);
>
> **(4) 问题下界:**
>
> 在无序数组中, 在遇到数 x 之前, 必须检查每个元素, 因此下界为 O(n)。该算法是最有效算法。

**1.10**

设有两个在同一台机器上实现的算法，运行时间分别为 $100n^2$ 和 $2^n$。当 n 取何值时，前者比后者快？

**答:**

> 令 $100n^2$ < $2^n$;
>
> - 取 n = 14 时, $100n^2 = 19600, 2^n = 16384$; 不等式不成立;
> - 取 n = 15 时, $100n^2 = 22500, 2^n = 32768$; 不等式成立;
>
> 故 n > 14 时, 前者比后者快。

**1.11**

假设在同一台计算机上比较插入排序和合并排序算法的效率。对于规模为n的输入，插入排序要运行 $8n^2$ 步，而合并排序要运行 $64nlgn$ 步。当n取何值时，插入排序的效率要优于合并排序？

**答:**

> 令 $8n^2 < 64nlgn$, 即 $n < 8lgn$;
>
> - 取 n = 8 时, 8 < 8lg8 成立;
> - 取 n = 9 时, 9 < 8lg9 不成立;
>
> 故 n < 9 时, 插入排序效率优于合并排序。
