# 第7章 贪心算法

#### 7.2

在任务选择问题中，假设不是选择最早结束任务，而是选择最晚开始任务。试说明这是一个贪心算法，并证明它能得到一个最优解。

答：

> 设: 任务 i 的开始时间为 a[i], 结束时间为 b[i], 所有任务处于 [0,T] 时间范围内; 
> 假设所有任务已经按 a[i] 递增排序, 则选择最晚开始任务的贪心算法如下:
> 
> - 从最后一个任务开始倒序寻找，选择第一个满足 b[m] <= T 的任务 m, 将 m 加入结果集合;
> - 将 T 更新为 a[m];
> - 重复上述过程, 直到没有满足条件的任务为止.
>
> 证明:
> 
> - 假设存在某个不含任务 m 的最优解, 该最优解中开始时间最晚的任务为 k, 则有 a[k] < a[m], 因此可以将 k 替换为 m, 得到一个新的最优解, 该解包含了 m. 故第一步选择最晚开始任务 m 是一个有效选择. 
> - 选择 m 之后问题变成了一个同构的子问题, 该子问题的最优解加上 m 就是原问题的最优解, 即该算法具有最优子结构性质. 
> - 综上所述, 选择最晚开始任务的贪心算法能够得到一个最优解.

#### 7.5

假设在0/1背包问题中，按重量递增所排的物品的次序与按价值递减所排的次序一样，请给出求这种背包问题最优解的有效算法，并分析其正确性。

答:

> 将物品按重量递增排序:
> - 物品序列: S = [s1, s2, ..., sn];
> - 重量序列: W = [w1, w2, ..., wn], 其中 w1 <= w2 <= ... <= wn;
> - 价值序列: V = [v1, v2, ..., vn], 其中 v1 >= v2 >= ... >= vn;
> 
> 贪心策略: 
> - 按正向顺序依次装入物品，直到背包装不下为止，可得到最优解。
>
> 有效性证明：
>
> - 第一步选择第一个物品 s1; 
> - 假设存在一个不包含 s1 的最优解, 该解中物品重量都大于或等于 w1, 价值都小于或等于 v1. 因此可以将 S' 中的任一物品替换为 s1, 得到一个新的最优解, 该解包含了 s1. 故第一步选择 s1 是一个有效选择.
> - 又已知背包问题具有最优子结构性质, 选择 s1 之后问题变成了一个同构的子问题, 该子问题第一步贪心选择同样有效;
> - 综上所述, 按重量递增所排的物品的次序与按价值递减所排的次序一样的背包问题, 选择物品的贪心算法能够得到一个最优解.



#### 7.8

将哈夫曼编码推广至三进制编码（即用符号0，1，2来编码），并证明它能产生最优三进制编码。

答:

> 设字符集中各字符的频率表为 f = [f0, f1, f2, ..., fn], 假设已经按频率递增排序, 则三进制哈夫曼树的算法如下:
>
> - 选择 f 中弹出最小的三个频率 f[0], f[1], f[2] 合成一个新的节点 p, 该节点的频率设为 f[0] + f[1] + f[2]; 若集合中只剩有两个频率, 就用两个合成;
> - 将 p 顺序插入到频率集合中;
> - 重复上述过程, 直到频率集合中只剩下一个元素为止, 该元素就是三进制哈夫曼树的根节点;
>
> 证明:
> 1. 贪心选择性质:
>   - 设最优三进制编码树为 T, 则 f[0], f[1], f[2] 必然在该树最深的三个叶子节点上; 假如不在, 可以通过与最深的三个叶子节点交换位置使编码更优, 因此 f[0], f[1], f[2] 必然在最深的三个叶子节点上;
>   - 假如这三个叶子节点不在同一父节点下, 则可以将它们调整到同一父节点下, 该调整不会增加编码的总长度, 因此仍然是一个最优解;
>   - 故第一步选择频率最小的三个字符合成一个新的节点 p 是一个有效选择;
> 2. 最优子结构性质:
>   - 选择 f[0], f[1], f[2] 合成一个新的节点 p 之后, 问题变成了一个同构的子问题, 该子问题的最优解加上 p 就是原问题的最优解, 即该算法具有最优子结构性质;
> 3. 综上所述, 三进制哈夫曼树的算法能够得到一个最优三进制编码.

#### 7.11

A驾驶着红旗牌轿车沿着107国道从深圳开往北京。A的车加满油时，可以跑n公里。A有张地图，标出了沿途中加油站之间的距离。为节省时间，A希望在路途中尽量地少加油。请设计出一个有效算法帮助A决定该在哪些加油站加油，并证明你的算法能够得到最优解。

答:

> 设加油站之间的距离为 d = [d1, d2, ..., dm], 其中 di 表示第 i 个加油站与上一个加油站之间的距离; A 的车加满油时可以跑 n 公里, n >= max(d); 则 A 的加油策略如下:
> - 从起点开始, 依次检查每个加油站与当前所在位置的距离, 直到找到第一个加油站 k 满足 dk > n, 则在上一个加油站 k-1 把油加满; 把当前所在位置更新为 k-1, 重复上述过程, 直到到达终点.
>
> 证明:
> - 用 ai = 1 或 0 表示在第 i 个加油站是否加油; 则任意一个最优解都可以表示为一个二进制序列 a = [a1, a2, ..., am]; A 中 1 的个数即表示加油的总次数; 
> - 按照贪心策略, 选择第一个满足 dk > n 的加油站 k 的上一个加油站 k-1 加油; 即 a[k-1] = 1, a[k-1] 之前都为 0;
> - 假设存在一个最优解在 a[k-1] 之前有 1, 而 a[k-1] = 0, 则可以将 a[k-1] 置为 1, 将之前的1置为0, 新的解加油次数只减不增, 仍然是一个最优解; 即第一步的贪心选择策略是有效的;
> - 选择 k-1 加油之后, 问题变成了一个同构的子问题, 该子问题的最优解加上 k-1 就是原问题的最优解, 即该算法具有最优子结构性质;
> - 综上所述, A 的加油策略能够得到一个最优解。
